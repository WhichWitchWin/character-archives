# 人物档案馆（character-archives）

DSH Tavern 插件。把游玩中出现、**具有后续价值的非龙套人物**收进「人物册」（**第一次被判定为非龙套就建档**）。每轮正文生成前，插件把**在场人物各自"知道什么"**整理成一小段参考塞给正文模型，让角色前后一致；**离场的人不塞**——正文里刚写过他，用不着再念一遍。面板里可以查一个人「他是什么样」和他「知道些什么」。主角本人也占一档（`p0`）。

- 以**人物为中心**保存内容，不按剧情保存，不做剧情流水账
- 人物书属于**当前这一局**，随剧情回退、分叉，由酒馆自动处理
- **非龙套就建档（在场也建）**；离场只是状态变化

## 怎么装

DSH Tavern 的插件**就是一个文件夹**：把 `plugin/` 整个复制到酒馆数据目录的 `plugins/` 下即可，不需要编译、不需要装依赖、不改酒馆源码。

```text
~/.dsh/profile-data/tavern/data/plugins/
└─ character-archives/
   ├─ package.json
   ├─ index.mjs     宿主侧
   ├─ client.js     浏览器侧
   └─ lib/
```

本地开发用：

```bash
npm run install:dev
```

## 怎么用

打开一局游戏后：**侧栏「＋」→ 插件 → 人物档案馆**。

这一页分四个标签页：**档案**（在场／离场／冷档的人物、搜索、查某人知道什么）、**设置**、**提示词**（三段跟模型说话的模板都能改，点「恢复默认」回到内置那份）、**预设**（栏目定义与勾选）。都不占「酒馆状态」页。

## 结构

```text
plugin/            插件本体（复制进 plugins/ 即可运行）
├─ index.mjs       宿主侧入口：apply(ctx)
├─ client.js       浏览器侧：侧栏面板
├─ prompt.js       三段提示词的兜底副本（由 assets/*.txt 生成，别手改）
├─ assets/         三段提示词的默认版 + 分词词表
└─ lib/            纯逻辑模块（不碰酒馆接口，可本地单测）
docs/              设计稿（规格）、ADR（决策）、ROADMAP（路线）
tests/             单元测试
scripts/           开发脚本（装到酒馆、同步提示词副本；重启脚本跟本机路径绑定、不入库）
```

## 状态

骨架、存档、召回、写回、面板、导入导出**都已接线能跑**：正文生成前召回、结算后自动判人＋写档案（子代理或常驻成员），面板里能查、能改、能拖。**跨插件接口还没做**（设置页「可见性」整组三项都已隐藏，因为点了不生效）。

各版本的目标、验收标准与还没做完的项见 [docs/ROADMAP.md](docs/ROADMAP.md)。
