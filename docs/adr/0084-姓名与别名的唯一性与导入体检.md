# ADR 0084 · 姓名与别名：一局内唯一、可改但不能留空

- **日期**：2026-11-04
- **状态**：已定并已实现
- **相关**：[ADR 0044](0044-姓名升到人物级别.md)、[ADR 0048](0048-模型只报人名.md)、[ADR 0049](0049-砍掉同名.md)、[ADR 0050](0050-导出必须带预设.md)、[ADR 0067](0067-名字必须来自正文.md)

## 背景

姓名是召回与写入**唯一的门牌号**：模型只报人名（ADR 0048），程序靠姓名／别名定位人。重名时按「绝不猜」直接返回空（ADR 0049），那个名字从此写不进去——而且是**静默**的。

早前有一条悬案：「别名允许同名」只记在交接笔记里，从未落成代码。这次定死。

## 决定

1. **唯一范围＝一局**。姓名与别名放在**同一个池子**里、全局唯一——这里的「全局」指**这一局的整份人物册**，不是插件的所有对局。别的局有同名的人完全没事（快照本来就按 `gameId` 存）。
2. **姓名不许留空**；别名可以为空串，但**别名那一格必须在**（人物是固定 5 格数组：编号、状态、姓名、条目、别名串）。
3. **允许玩家改姓名**（面板 `✏` 或双击名字）。新名字同样不许留空、不许撞名（含他自己的别名、含主角名）。
4. **姓名留空的人**：不召回、不写入。写入侧在 `resolvePersonByName` 返回 null；召回侧要求「姓名位必须非空」才进池（ADR 0044——旧 `recallPipeline` 已于 2026-11-04 退役，新引擎沿用这条）。
5. **导入必须体检**：逐人查 5 格齐、编号／状态／姓名／条目／别名的类型、姓名非空、姓名与别名全局不撞；不合格**整包拒绝**，并说明是第几个人、谁和谁撞了。

## 为什么

- **撞名 → 静默跳过**：这是最难查的一类问题（没有报错，只是那个人从此写不进去）。导入时一次拦干净最省事。
- **空姓名 → 召不回也写不进**：留着只会在面板上挂一个看不见的幽灵。
- **允许改名、拒绝留空**：改名是正常需求（模型起的名不好、错字、改口），但空名没有任何意义。

## 与建档规则的差异（有意为之）

- **模型建档**时「姓名＝自己的别名」会**静默去掉别名**（宽容——模型产出的脏动作不该整条作废，见 `actions.js` 的 `checkAliases`）。
- **导入与改名**是**玩家显式操作**，同样情形直接拒绝并说清原因。

两处口径不同是有意选的，不是遗漏。

## 补充：同日 review 后修掉的三处（2026-11-04）

只读 review 抓到三个会让这条 ADR 直接失效的问题，一并修了：

1. **别名分隔符口径不一致**：存储与唯一性判断只按半角逗号切，匹配层却按 `,，、` 切——模型写出「老陈头，掌柜」时，撞名体检查不出「掌柜」，但匹配层能命中它，撞名照样会静默丢数据。新增 `lib/names.js` 作为**唯一口径**（`splitAliases` / `joinAliases` / `namesOfPerson`）：存储统一用半角逗号，解析三种分隔符都认。
2. **主角名守卫恒不生效**：`settings.mainNames` 这个键根本不存在，`?? []` 让它永远是空数组。手动新建与改名改用 `identity.playerName`（与模型建档链路一致），导入体检也把主角名传进去。
3. **带括号的名字写不进去**：「老王（大爷）」会被 `resolvePersonByName` 当成「名字(p7)」的编号尾巴，取括号内容当编号、失败直接返回 null。改成**先按完整名字匹配**，再走编号与尾巴解析。

**顺带补上**：导入体检增加「编号不重复」；姓名与别名支持**一次提交**——分开改会卡死（别名不许等于现在的姓名，姓名又不许撞现在的别名），一起提交则按「提交后的样子」校验，把旧姓名挪进别名一步就能完成。

## 补充：名字的输入限制（2026-11-04，同日定）

**名字里不许出现会影响写入或召回的符号**，一律在前端输入处拒掉，**不做「特殊输入也能用」的兼容**：

| 符号 | 为什么禁 |
|---|---|
| `（）` `()` | 素材里重名者写作「老陈(p7)」，名字里带括号会跟这个编号尾巴的解析打架 |
| `,` `，` `、` | 那是别名的分隔符，名字里带它会被切成两个人名 |
| 引号、反斜杠、尖括号、大括号、方括号、反引号、控制字符 | 破坏 JSON 与面板显示（原本就禁） |

实现：`lib/inputLimit.js` 的 `checkText(text, label, { kind: 'name' })` 用**更严的白名单**——只留汉字、字母、数字、`·`、`-`、空格。建档（姓名／别名／模糊建档名单）、改名、导入体检全部走这一处，不再各留一套规则（原来 `actions.js` 里那套黑名单 `checkNameChars` 已删）。

名字是门牌号：**宁可让玩家改一个字符，也不要让程序去猜他想指谁**。带括号的「老王（大爷）」，请玩家写成「老王」或另加别名。

### 所有输入口的边界（同日补齐）

| 输入口 | 限制 |
|---|---|
| 姓名／别名／模糊建档候选／导入人物 | **名字白名单**：汉字、字母、数字、`·`、`-`、空格；≤ 24 字 |
| 玩家称呼 | 同上；**存量脏值读回来当作没填**（别把脏值带进提示词），改的时候直接报错 |
| 栏目名（手动新建 + 预设保存） | 正文白名单；≤ 24 字（会拼进提示词表格） |
| 栏目说明 | 正文白名单；≤ 500 字 |
| 条目值 | 正文白名单；≤ 30 字（原有，ADR 0022） |
| 三段提示词 | **只卡长度 ≤ 30000 字**——自然语言里有换行、引号、括号，套字符白名单会直接废掉这个功能 |
| 设置项 | 数字范围与枚举（原有） |

原则：**名字和标识类**用严白名单，**自然语言类**只卡长度。别把两套搞反。
