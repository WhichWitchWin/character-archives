# ADR 0106 撤回只写「谁」；约定细则回到系统提示词

- **日期**：2026-11-06
- **状态**：已定并已实现
- **相关**：[ADR 0102](0102-撤回指针.md)（撤回指针，本条改它的字段名）、[ADR 0087](0087-约定类命题程序只存不判断.md)（约定状态）、[ADR 0095](0095-系统提示词拆固定与动态.md)（固定规则＋动态上下文）、[ADR 0105](0105-系统提示词体检.md)（本条推翻它「约定细则按需发」的决定）

## 背景：同一个「关于」，两个块里意思相反

玩家追问「撤回里的『关于』到底指谁」，查代码发现是**同名不同义**：

| 位置 | `关于` 实际指 | 证据 |
|---|---|---|
| `命题[]` 里 | **命题说的是谁** | `writeActions.js`：`aboutId = resolvePerson(action.关于)`，再要求 `claim[1] === aboutId` |
| `撤回[]` 里 | **持指针的人（改口的人）** | `retract.js`：`resolvePerson(item.关于)` 得到的 id 直接去匹配 `pt[0]`（指针第一格＝谁持有） |

指针形状是 `[谁持有, 指向哪条命题, …]`（`pointers.js` 的 `addPointer`），命题第一格才是「说的是谁」。所以撤回里填 `关于:"主角"` 是把「持指针者」塞进了一个语义为「命题主体」的字段名里——模型按 `命题.关于` 的习惯填，就会摘错人。

**原测试测不出这个区别**：用例是「沈清禾撤回关于她自己去向的旧说法」，持指针者和命题主体恰好是同一个人，填谁都过。

## 决定

### 1. 撤回块改成 `{ 谁, 序号 }`

```json
{ "撤回": [ { "谁": "改口的人", "序号": 3 } ] }
```

- `谁` ＝ 持指针的人（**与 `认知[].谁` 同义**），必填、必校验；
- 序号已唯一锁定命题，**命题说的是谁由程序按 `claim[1]` 查，不要模型报**——所以不新增第三个字段（加 `关于` 只会多一个能填错的地方）；
- **只认 `谁`**：带旧字段 `关于` 的撤回条目直接丢弃（`parseRetracts`）。撤回是每轮即时应用、不归档的，兼容包袱很小；留着两套写法会让提示词又得多写一句口径。

### 2. 调试日志显示「谁 → 关于谁 · 命题内容」

`applyRetractions` 的返回值新增 `aboutId` 与 `claimText`（在 `dropClaim` 之前抓，命题被清掉也带得回来）；`index.mjs` 的日志改成：

```
撤回 1 条认知
  小s → 关于 沈清禾 ·「地铁十号线车厢」  连带清掉命题: 否
```

`claimText` 可能是字典下标，日志侧用现成的 `decodeValue` 解码。这样玩家能直接看出「撤掉的是谁的哪条认知」，而不是只看到一个命题编号。

### 3. 约定细则回到固定系统提示词（推翻 ADR 0105 第 3 条）

约定四状态（没完成／完成了／过期了／失败了）、沿用条件（正文没提**且约定时间还没过**）、一条带 `约定` 字段的示例，全部从 `buildContextText` 的【约定规则】段搬回 `system-prompt.txt` 的「四、态度与来源」，并写明「只有【栏目定义】表里标了【约定】的栏目才用；本局没有约定栏目就别带这个字段」。

**为什么反转**：ADR 0105 的理由是「默认 8 栏都没勾约定，每轮白发 421 字」。但按 ADR 0095 的原则，**约定规则不随局变，属于固定内容，固定内容该放固定处**——固定提示词能被模型缓存，放在每轮的动态上下文里反而是每轮全价重发。所以回到固定处既更符合原则，缓存命中也更省。

`buildContextText` 的 `definitions` 参数保留但不再使用（标注为兼容既有调用方），删除【约定规则】段。

## 代价与边界

- **旧格式不兼容**：模型若仍写 `{关于,序号}`，撤回会被丢弃并在调试里显示「撤回被拒」（原因：撤回要写清「谁」和「序号」）。**未实测**模型适应情况；
- **`definitions` 变成无用的参数**：暂留以缩小改动面，将来清理时可以删；
- **系统提示词变长**：5691 字（+359），但换来的是固定内容可缓存 + 撤回字段不再歧义；
- **仍需重启 DSH**：`index.mjs`（工具说明、日志）属宿主侧；
- **守卫**：`tests/retract.test.mjs` 新增「主角撤自己对沈清禾的认知」「返回体带 aboutId／claimText」「旧字段不再收」「日志带关于谁与 decodeValue」；`tests/promptTemplates.test.mjs` 新增「约定细则在系统提示词」「撤回只写谁和序号」；`tests/followup.test.mjs` 改为断言约定规则**不再**随工单发；全量 **771 全过**。
