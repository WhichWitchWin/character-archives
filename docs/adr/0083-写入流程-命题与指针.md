# 0083 写入流程：从命题到指针

- **状态**：已定（待实现）
- **日期**：2026-11-03
- **相关**：[ADR 0081](0081-信度改成事实加指针-提案.md)、[ADR 0032](0032-判定素材带状态.md)、[ADR 0048](0048-模型只报人名.md)、[ADR 0023](0023-值级动作集与输出格式.md)
- **起因**：信度改成「命题 + 指针」后，写入的素材、输出格式、校验规则全部要重做

## 阶段一：判定（复用现有的一次调用）

```
程序扫正文 → 候选人物（已建档 + 模糊建档）
        ↓
模型读正文 + 候选 → 返回：在场名单 / 建档 / 改状态 / 模糊建档
        ↓
程序过滤：只留已建档的
```

在场名单由**模型给**，不用程序撞库——`提到 ≠ 在场`本来就是模型判断题（ADR 0032）。

## 阶段二：组装素材

**给每个在场人物 A**，A 的指针里指向下列命题的：

| # | 筛什么 |
|---|---|
| ① | 所属人物 ∈ **在场人物**（含 A 自己） |
| ② | 涉及**当前地点** |
| ③ | **有效期覆盖当前时间**（没过期） |
| ④ | 索引词**命中本轮正文** |

**外加**：正文提到、但**不在场**的、命中人物库的人 → 他们**全部勾选条目**的现有命题。**只读**，模型不能给他们建指针。

不握手，一次给全（写入模型预算够）。

## 阶段三：模型输出

一条动作 = **一条命题 + 若干指针**：

```json
[
  {
    "关于": "B",
    "栏目": "位置",
    "值": "在旧港",
    "序号": 3,
    "索引词": [{ "词": "旧港", "类": "地" }],
    "认知": [
      { "谁": "A", "来源": "自己", "态度": "真" },
      { "谁": "C", "来源": "A",    "态度": "未定" }
    ]
  }
]
```

| 字段 | 含义 |
|---|---|
| `关于` | 这条命题说的是谁 |
| `序号` | 可选，指向素材里的现有命题 |
| `谁` | **这条认知属于谁** |
| `来源` | `自己`＝该角色本人的认知（不限于亲眼）；人名＝那人告知他形成的认知；`未知`＝路人、信、书、传闻，或任何不在写入素材里的人 |
| `态度` | **他信不信这个来源的说法**：真／假／未定 |

> 命名区分：**人物级用「状态」**（在场／离场，客观事实），**认知级用「态度」**（真／假／未定，主观认知）。早前两级都叫「状态」，模型容易串（ADR 0083 后续修订）。

## 阶段四：程序处理

**① 找命题**（四步，前一步失败才走下一步）

| 步 | 检查 | 失败 |
|---|---|---|
| 1 | 有 `序号` 吗 | → 3 |
| 2 | 序号指向的命题，值对得上吗 | **模型数错**，→ 3 |
| 3 | `栏目 + 值` 精确匹配 | → 4 |
| 4 | `looseKey` 宽松匹配 | → **新建命题** |

**② 建/更新指针**

| 模型报的 | 程序动作 |
|---|---|
| `来源: 自己` | 改这个人的「自己」那组 —— **例外通道**，记调试 |
| `来源: 某人` | 追加/更新他述组 |

**③ 守规则**：这个人已有「自己」那组时，别人报的只能动他述组。

## 阶段五：规则汇总

| 规则 | 内容 |
|---|---|
| **命题由指针带出** | 没指针就没命题，**不存在孤儿命题** |
| **认知提供人不单独建指针** | 他提供的认知已出现在接受者的「来源」里；**除非他自己也有对这条命题的认知**，那就按他自己的流程走 |
| **命题一律正向** | 「B 没死」不是新命题，而是「B 死亡」＋ 某人态度「假」 |
| **传播即建** | 一个人告诉另一个人，听者才建 |
| **一人一命题一条指针** | 多个来源塞进这一条，不建多条 |
| **态度是「信不信这个来源」** | 不是"说对没有" |
| **有自己那组 → 别人的取反** | 自己真 → 别人说的相反就是假（模型判断，程序不算） |
| **没有自己那组 → 别人一律未定** | 不知道谁对 |
| **洗脑 = 改「自己」那组** | 唯一能绕过「别人动不了自己」的通道 |
| **他述信度低于自己** | 本人亲眼可覆盖，别人不行 |

**计划类命题**：

| 结局 | 旧命题 | 旧指针 | 新命题 |
|---|---|---|---|
| 进行中 | 保留 | 保留 | — |
| 成功 | **删** | 删 | — |
| 失败 | **删** | 删 | 「A 找 B 复仇失败」+ **A 的指针 → 真** |

> **2026-11-04 更正**：上面这套「成功删／失败转写」已被 [ADR 0087](0087-约定类命题程序只存不判断.md) 取代——程序**只存不判断**，结局由模型写进指针的约定状态（第 5 格），命题不删、也不封任何有效期。

**命题不删、也没有过期机制**：原文写的「结束轮」已删除（2026-11-04）——从来没有代码写过它，`结束轮 === 0` 恒为真，是个空闸。约定类也不靠它，靠指针第 5 格的约定状态（ADR 0087）。

## 存储

```js
// 命题表
// 命题表（6 格；结束轮与约定轮次都已删）
[id, 所属人物, 栏目码, 内容, 起始轮, 索引词]

// 指针表
[人物id, 命题id, [[状态, 来源], ...], 建立轮]
// 状态 0真/1假/2未定；来源 ''自己 / 'p7'某人 / '?'未知来源
```

**约定时间挂命题上**（"5 点见面"是命题内容的一部分）。别人的来源组最多留 3 组。

## 校验清单

1. `关于` 的人存在
2. `栏目` 存在
3. `态度` ∈ 真/假/未定
4. `来源` ∈ 自己/已建档人名/未知
5. `序号` 越界或不属于该人物 → 拒绝
6. 有「自己」组时，别人报的只动他述组

## 调试记录

每次出现 `来源: 自己` 的改动，记一条：

```
第 N 轮 | 改了「老陈」的自我认知 | 命题 12「B 死亡」| 真 → 未定 | 原文片段：…
```

用于事后排查模型是否滥用这个通道。
