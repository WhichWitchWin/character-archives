# ADR 0104 两类命题的态度：能观察的可以真，推断出来的只能未定

- **日期**：2026-11-06
- **状态**：已定并已实现
- **相关**：[ADR 0103](0103-亲见不自动算真.md)（亲见不自动算真，本条补它治不到的那一半）、[ADR 0020](0020-写入判断带上视角说明.md)（默认态度未定）、[ADR 0083](0083-写入流程-命题与指针.md)（命题＋指针）、[ADR 0098](0098-认知模型四个旋钮.md)（认知四旋钮）

## 背景

玩家指出一件更根本的事：**即使「亲见算真」开着，「爱试探陌生人的底细」也不该算真。**

当时的实况（第 3 轮）：

```json
{ "关于":"沈清禾", "栏目":"性格", "值":"爱试探陌生人的底细",
  "认知":[ { "谁":"小s", "来源":"自己", "态度":"真" } ] }
```

排查下来有两条原因叠在一起：

1. 口径里写着「主角亲眼见到的，可以直接给『真』」，模型把"他就在旁边看着"套成了亲见；
2. **更要紧的**：系统提示词里「真」的定义是**「该角色信这个说法」**——它的心理活动是"小s 观察到了，所以小s 信"，按这个定义给真**并不违规**。

也就是说：只调「亲见算不算真」这个旋钮治不了这件事，因为缺口在"**哪些命题配得上『真』**"这一层——提示词从头到尾没有区分「看得见的事实」和「推断出来的性质」。

## 决定

系统提示词「四、态度与来源 → 怎么判断态度」后面新增一段，**与亲见设置无关，永远这么判**：

```text
**两类命题的态度不一样**（跟「亲见算不算真」的设置无关，永远这么判）：

· 能直接观察的事实——他在哪、做了什么、说了什么、身上有什么伤：亲见或正文明确写出来的，可以给「真」。
· 推断出来的东西——性格、动机、想法、关系性质、评价：不能给「真」，只能给「未定」；
  除非正文里有人明确这么说、而这个人明确信了（那才写「真」）。

  例：「她在十号线车厢」＝可观察 → 亲见可给真；
      「她爱试探陌生人的底细」＝推断 → 给「未定」，哪怕你亲眼看见她在试探。
```

## 为什么

- **「真」的语义是"他信"**：既然是信念层，就必须说清"什么才算他真的知道"，否则模型会用"他看过/他想过"去填满「真」；
- **推断与观察的证据强度不同**：看见她试探 → 可以确信"她在试探"；但"她爱试探"是跨情境的概括，一次观察撑不起。面板把两者显示成同一个「真」，玩家就会把推测当事实；
- **不改数据结构**：不加"推断"这个第四种态度，也不新增字段——只在提示词里划清界线，代价最小。

## 代价与边界

- **仍靠模型自觉**：这是提示词约束，不是程序校验；**未实测**，要跑几轮看性格／关系类命题的态度分布；
- **"关系性质"需要判断**：「他是我的旧友」若有人明确说过，仍可给真；只有**没人明说、纯靠观察归纳**的才必须未定；
- **与 ADR 0103 分工**：0103 管"亲见不自动算真、按正文表现判断"，本条管"哪些命题天生不配真"——两条一起才完整；
- **守卫**：`tests/promptTemplates.test.mjs` 新增 1 条（锁住"两类命题的态度不一样"、可观察／推断两行、"不能给真"、五个典型种类），全量 **754 全过**。
