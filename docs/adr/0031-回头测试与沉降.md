# 0031 回头测试与沉降：入口一道窄门，出口一层兜底

- **状态**：有效
- **日期**：2026-11-02
- **supersedes**：[ADR 0024](0024-建档提前.md) 中「非龙套判定只有四条并集」这一条（现在多了「回头测试」这道前置关）

## 背景

### 1. 现状会把一次性背景板收进来

原判据是四条**并集**，其中两条几乎没有门槛：

> ① 与主角有实质互动：对话涉及信息、**交易**、冲突、承诺

「主角去小商贩那里买条鱼」——有对话、是交易 → 满足 ① → 当场建档。

于是卖鱼的、卖菜的、打酒的、报信的路人，全都会进档案。

### 2. 危害不在"吵"，在"死档"

档案建了，可它永远召不回来：

- 召回靠**姓名／别名／关联词**匹配；
- 「小商贩」「路人」「侍卫」这类**通用称谓**，在正文里一搜一大把；
- 就算命中了，召回的也是"某个小贩"，不是"他"。

**召不回来的档案就是死档**——占着面板、占着预算、还让人以为档案很全。

### 3. 试过但否掉的两条路

- **加「后续性」闸门**（"这个人以后还会不会再出现"）：要模型**预测未来**，模型最爱干的事就是给自己找理由，闸门形同虚设；
- **加反向清单**（买鱼、买菜、问路……）：黑名单永远列不完，而且会误伤（"买鱼"但鱼里有毒，这种恰恰该收）。

两条都在**判据**上打补丁，且都要模型做**判断题**。

### 4. 也试过「出现 ≥ 2 轮」当硬门槛，被否

那等于把 [ADR 0024](0024-建档提前.md) 解决的**冷启动**问题请回来：第 1 轮不建，第 2 轮才建，而**正文只发本轮**——第 1 轮他说过的话、做过的事一个字都进不来。

**结论：门槛必须是「当场能判」的。**「轮次」天生要等，只能当依据，不能当前置条件。

## 决定

### 1. 入口：回头测试（当场可判）

> **站在街上喊这个称呼，会只有他一个人回头吗？**

| | 例 | 判断 |
|---|---|---|
| ✅ 专名 | 老陈、独眼陈、刀疤刘 | 只有一个回头 |
| ✅ 反常 | 瞎眼的鱼贩、独臂铁匠 | 同行标配之外的特征 |
| ✗ 通用称谓 | 小贩、路人、侍卫、伙计、黑衣人 | 喊一声一堆人回头 |
| ✗ 同行标配 | 骑电瓶车的外卖小哥、戴头盔的外卖小哥、系围裙的鱼贩 | 电瓶车／头盔／围裙是这行的标配，十个回头 |

配一句原则：**同行的标配不算标识，反常才算。**

- **过不了这道关 → 不建档**；
- 称呼**必须来自正文里怎么叫他**，不许模型自己起名（否则它会给每个龙套编个"鱼贩老赵"）；
- 过了这道关，仍按原来的四条并集判够不够格，**当场建，不拖**。

这道关**不判"他重要不重要"**（判不了），只判"他有没有一个能找回来的名字"（判得了）。

### 2. 出口：沉降（冷档）

**是算出来的，不是存字段**：

```
gap  = 当前轮次 − 最后确认轮次
沉降 = gap ≥ 沉降轮数  且  非★  且  未手动锁定
```

- 默认 **20 轮**，可调 5～999（999＝不沉降）；
- `最后确认轮次` ＝ max(所有值的轮次, 最近一次在正文里被提到的轮次)，**已有数据现算**；
- 因为是现算而不是存字段，**回退时自动正确**，不用进回退表，也不会漂。

沉底后只发生三件事：

| # | 变化 |
|---|---|
| ① 面板 | 折叠成「冷档（N）」，默认收起，点开可见全部 |
| ② 召回 | 正文**明确写出姓名／别名 → 照常召回**；只沾到关联线索 → **不召回** |
| ③ 排序 | 不参与按时效分／关键度往上顶的主通道 |

浮起来：本人出场／被提到名字／写入新值／玩家编辑／点★ —— 任何一件都刷新 `最后确认轮次`，gap 归零，立刻回活跃区。

## 后果

- **收益**：一次性背景板在入口就被挡住；漏网的也会在 20 轮后自动沉底，**两道筛子叠加**，不再需要在"太松／太严"之间反复摇摆。
- **收益**：沉降不占存储、不进回退表、不加状态值，实现成本极低（一个纯函数）。
- **代价**：有普通名字的路人（"卖鱼的王二"）仍然会被建。影响有限——档案小、正文提"王二"的概率低、20 轮后照样沉底。
- **代价**：回头测试仍是**模型判断题**，"什么算同行标配"靠世界知识，会有误差。
- **边界**：★ 人物与手动锁定 🔒 的人永不沉降。
- **未解决**：沉降治的是"面板吵"和"召回误伤"，**不治存储**。人物总数上限是另一个话题，不要混进来。

## 被否决的方案

- **只做回头测试、不做沉降**：漏网的（"卖鱼的王二"）会一直留在活跃区。
- **只做沉降、不做回头测试**：入口太宽，前 20 轮面板会很吵，召回预算也会被挤。
- **「出现 ≥ 2 轮」当硬门槛**：把冷启动请回来，第 1 轮内容全丢（本 ADR 背景第 4 条）。
- **给人物加「已沉降」字段**：要写盘、要进回退表、会漂，而且等于新增一个状态；现算全都不需要。
- **沉降时删数据**：违反"沉底不是删除"，玩家回头想看就没了。

## 待定

- 「沉降轮数」默认 20 是拍的经验值，**实际跑起来可能偏早或偏晚**；等有实机数据再校。
- 冷档只响应"姓名／别名精确命中"——如果玩家自己给冷档人物改了名，命中词要不要同步更新（涉及别名双存，见 ADR 索引 Q17）。
