# ADR 0108 信度码退役：那套 `"0"`～`"9"` / `r42` 已经不在了

- **日期**：2026-11-06（**追溯记录**：记录的是 2026-11-01～11-03 之间发生的退役，当时没单独立档）
- **状态**：已定并已实现（代码里已无残留）
- **相关**：[ADR 0016](0016-召回注入格式.md)（召回注入格式，信度标签的展示形式）、[ADR 0019](0019-信度拆成两维.md)（把信度拆成"来源 + 真值"两维）、[ADR 0081](0081-信度改成事实加指针-提案.md)（改成「命题 + 指针」两层）、[ADR 0083](0083-写入流程-命题与指针.md)（写入流程落地）、[ADR 0103](0103-亲见不自动算真.md) / [ADR 0104](0104-两类命题的态度.md)（态度的现行口径）

## 为什么要单独记这一条

`docs/DESIGN.md` 的 §7.10.3 里一直挂着一整套**已退役**的信度码表（`"0"`～`"9"`、`"X"`/`"N"`、`r42`），而且是半截的——表格中间被一段正文打断，渲染出来是断的。它既不是"当前状态"（DESIGN 的定位），散落在别的 ADR 里又拼不出全貌。所以把这段历史整体搬到这里，DESIGN 只留一句指针。

## 那套码是什么

早期版本里，**每条值条目都带一位「信度码」**，用来表示"这条信息是真是假、谁说的"。完整对照表（原文抄录，供考古）：

| 信度码 | 含义 | 注入时显示成 |
|---|---|---|
| `"0"` | 用户·真 | `主角确认过` |
| `"1"` | 用户·未定 | `主角记不清` |
| `"2"` | 用户·假 | `主角知道是假的` |
| `"3"` | 自述·真 | `他亲口说的，可信` |
| `"4"` | 自述·未定 | `他自称` |
| `"5"` | 自述·假 | `他自称，但这是谎话` |
| `"6"` | 他述·真 | `听人说的，后来证实了` |
| `"7"` | 他述·未定 | `只是听说` |
| `"8"` | 他述·假 | `听来的，其实是假的` |
| `"9"` | MVU | 不写来源 |
| `"X"` / `"N"` | — | 不写来源 |
| `r42` / `r42+` / `r42-` | 某个具体的人说的 | `林昭说的` / `林昭说的，可信` / `林昭说的，其实是假的` |

结构上它是**一维的**：一个字符同时编码了"谁说的"和"真不真"（`"6"` = 他述 + 真）。

## 为什么废掉：三步，每一步都踩在上一版的空处

### 第一步：一维码分不清两件事（[ADR 0019](0019-信度拆成两维.md)）

码表定义了**格式**，却没定义**语义**：「真／假」到底是客观真相，还是主角的判断？含混不清。

根因一句话：**写正文的模型手里没有"真相"**——它不知道哪个 NPC 在撒谎，让它判真假等于让考生自己判卷。

于是拆成两维：

```
信度 = 谁说的（来源） + 主角信不信（真值）
```

### 第二步：两维仍然是"主角视角"，在第三人称下崩（[ADR 0081](0081-信度改成事实加指针-提案.md)）

拆成两维之后，"用户"= 主角亲眼见到、"真值"= 主角信不信。**但第三人称切到主角不在场的场景**（反派密谋、支线）时，主角既没看见也不知道，而正文写得很清楚——这时真值只能标「未定」，模型读到的却是"这件事不确定"。

**「未定」被两个意思共用了**：真的不确定 / 主角不知道。

### 第三步：换成「命题 + 指针」两层（[ADR 0081](0081-信度改成事实加指针-提案.md) → [ADR 0083](0083-写入流程-命题与指针.md)）

- **命题层**（`snapshot.c`）：全局一份，存"有人提过、有人信过的一句话"，**不保证为真**；
- **指针层**（`snapshot.pt`）：每个角色各一份，表示"他信不信这件事、从谁那儿听来的"。

「态度」从"值的属性"变成了"**指针的属性**"——同一件事，A 信、B 不信、C 只是听说，各挂各的指针，互不干扰。一维码和两维表都装不下这个模型。

## 现在用什么替代

| 旧 | 新 |
|---|---|
| 值条目的 `信度码` 一位字符 | **指针的来源组** `[态度, 来源, 游戏时间?, 约定状态?]` |
| `"0"`~`"8"` 的九种组合 | **态度**三值：`真` / `假` / `未定`（`pointers.js` 的 `TRUTH`） × **来源**三类：`自己` / 某人名 / `未知`（`SELF` / `UNKNOWN_SOURCE`） |
| `"9"` MVU | 与**写入侧**无关：MVU 人物字段映射已整体退役（[ADR 0091](0091-MVU人物字段映射退役.md)），不再往档案里抄字段 |
| `"X"` / `"N"` | 语义并入「来源 = `未知`」 |
| `r42`（人名编码） | 直接存人物编号；模型只报人名，由 `resolvePersonRef` 解析（[ADR 0048](0048-模型只报人名.md)） |
| 值自带"信不信" | 指针自带；一条命题被十个人知道就有十条指针，各自独立 |

**态度的判法**另有两条现行规则，与本文无关但要一起看：[ADR 0103](0103-亲见不自动算真.md)（亲见不自动算真，默认按正文里他自己的表现判断）、[ADR 0104](0104-两类命题的态度.md)（推断出来的东西不能因为看见了就给「真」，这一句被 [ADR 0105](0105-系统提示词体检.md) 收窄为「不因看见就给真」）。

## 代价与边界

- **不需要数据迁移**：查证 `plugin/` 全目录（`*.js` / `*.mjs`），`r42`、`信度码`、`信度位` **一处都不剩**；快照的命题结构是 `[id, 人物, 栏目, 内容, 起始轮, 索引词]`，从来没有"信度"这一格。所以这套码只活在文档里，没有任何存档需要兼容；
- **文档层面已清理**：`docs/DESIGN.md` §7.10.3 的信度码表已删除，改为指向本文——顺带修掉了那张表"被正文打断、渲染断裂"的毛病；
- **别把本文当成现行方案**：现行的是"命题 + 指针"，看 [ADR 0083](0083-写入流程-命题与指针.md)；
- **ADR 0019 与 0081 都不改动**（ADR 按 append-only 记，本条目只做追溯汇总，不重写它们）。
