# ADR 0102 给模型一个「撤回」动作：只摘本人的指针

- **日期**：2026-11-06
- **状态**：已定并已实现
- **相关**：[ADR 0083](0083-写入流程-命题与指针.md)（命题＋指针）、[ADR 0085](0085-主角入档与召回规则.md)（主角入档）、[ADR 0087](0087-约定类命题程序只存不判断.md)（约定类只存不判断）、[ADR 0100](0100-后台成员交卷按派发时定的盒子.md)、[ADR 0101](0101-主角必须在写入之前入档.md)

## 背景

实际对局里出现：

```
沈清禾 · 最后已知去向 ·「地铁十号线车厢，往国贸方向」（第 2 轮）
沈清禾 · 最后已知去向 ·「国贸站B口外的星辰数科写字楼」（第 3 轮）
指针：主角和她本人各指向这两条
```

也就是说**她本人同时"知道"两个互相矛盾的去向**。这不是模型写错——第 2 轮那条在当时是真的；问题是数据层没有「这个人改口了」的表达方式：模型只能不断新增命题，撤不回来。

一开始考虑过「单值栏目写入即取代」，被否：**不同认知主体可以各信一版**（A 以为 B 去了 C 地，D 只知道 B 去了 F 地）。所以「过时」这个概念必须落在**指针**上，不能落在栏目上。

## 决定

在交卷对象的顶层加一块，跟 `命题` 平级：

```json
{ "撤回": [ { "关于": "沈清禾", "序号": 3 } ] }
```

程序侧（`lib/retract.js` 的 `applyRetractions`，在**写入之后**跑）：

| 闸 | 规则 | 拒绝原因 |
|---|---|---|
| 人物 | `关于` 必须解析得到已有档案 | `人物「X」不在档案里` |
| 在场 | 只认**在场人物**（跟「只有在场的人才能获得新认知」同一条规矩） | `「X」这轮不在场，不能撤回他的认知` |
| 序号 | 必须在本轮**素材**的序号表里（模型看不见的命题不许动） | `序号 N 不在本轮素材里` |
| 存在 | 这人本来就指着那条，才谈得上撤 | `「X」本来就没有这条认知` |
| 结果 | 摘掉**他一个人**的那一条指针；若这条命题**零指针**了 → 立即清掉命题 | — |

- **排在写入之后**：写入可能用 `序号` 复用旧命题，撤回先把命题删了会让那些序号失效；
- **零指针立即清**，不等下一轮孤儿清理——撤回是显式否定，留一轮没有意义；
- **别人的指针一根不动**：她改口不等于别人知道她改口；
- 每次撤回的明细进调试日志（`撤回 N 条` + 人物／命题／是否连带清掉命题）。

系统提示词新增「撤回」三条（只在她自己改口时用、不许替别人撤、序号只能用素材里印出来的），输出示例里带上 `"撤回"` 块。

## 为什么

- **责任在数据层，不在模型**：把「过时」交给程序按指针语义处理，模型只需要表达"这个人不信了"，不用每轮判断"这条算不算过时"；
- **复用既有孤儿清理**：命题"只要还有人指着就活着"本来就是现有语义（`pruneOrphanClaims`），撤回只是让模型能主动松手；
- **不给它管理员级删除**：撤回只能碰「这一轮摆在它面前、且这人自己信过」的命题，删不了别人的认知、删不了它没看见的东西。

## 代价与边界

- **仍是软约束**：模型可能滥用（把不想留的都撤掉）或用不出来。三道闸只是边界，不等于它一定用得对；**未实测**；
- **撤回不删命题**：命题只在没人指着时才消失，这条写死在实现里；
- **与面板删除的区别**：面板删除是玩家权限、不可撤销；撤回是"认知层"的，且只有模型在最新一轮里能提出；
- **同一轮里既撤又写**：`撤回` 与 `命题` 各自独立应用，互不抵消；
- **守卫**：`tests/retract.test.mjs` 10 条（只摘本人／零指针清命题／不在场拒／序号不在素材拒／本来没有拒／人物不存在拒／解析三条／接线顺序），提示词另有 1 条守卫。
