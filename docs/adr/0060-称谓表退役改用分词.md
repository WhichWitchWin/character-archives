# 0060 称谓表退役，改用中文分词；单字名不再强制配别名

- **状态**：有效
- **日期**：2026-11-02
- **supersedes**：[ADR 0010](0010-单字命中细则.md) 整条（称谓表 + 边界启发式）；[ADR 0059](0059-别名查撞与单字名.md) 的「单字姓名必须配 ≥2 字别名」

## 背景

匹配层原来是**字串包含** `text.includes(name)`，中文没有空格，于是靠一堆启发式去猜词边界：

| 补丁 | 作用 |
|---|---|
| `HONORIFIC`（老/小/阿 + 老板/先生/总/哥/姐/叔） | 猜「周老板」是不是在叫「周」 |
| `LEAD_IN` / `LEAD_FORM` / `TRAIL_IN` | 猜前后的字是不是虚词 |
| `isStandalone` / `hasHonorific` | 玩家输入 / 正文两套口径 |

问题很明显：**漏得比挡的多**。「周掌柜」不在称谓表里就认不出；而且这张表要人肉维护，加不完。

现在存储搬出酒馆（[ADR 0057](0057-自持文件存储.md)/[0058](0058-数据放插件数据区.md)），空间不再是约束，可以带一份真词表了。

## 决定

### 1. 引入分词：`lib/segment.js` + `assets/dict/zh.txt`

| 项 | 值 |
|---|---|
| 词表来源 | jieba 0.42.1 `extra_dict/dict.txt.small`（MIT，见 `assets/dict/LICENSE-jieba.txt`） |
| 处理 | 去掉词性标注，只留「词 词频」 |
| 规模 | **109,758 词 / 1.34 MB / 最长 15 字** |
| 算法 | 按词频的**动态规划路由**（不是贪心最大匹配） |

两个实测踩到的坑：

1. **贪心会退化**：真实词表下贪心把「周末」切成 `周|末`。必须用 DP。
2. **必须减 `log(总词频)`**：否则 `周(8326) + 末` 的分数高于 `周末(654)`——多切一个词就多一个正分。加上归一化后"每多切一个词罚一次"，长词自然胜出。

### 2. 用户词典：每轮灌人名

人名通常不在通用词表里，所以接线处每轮把**当前人物的姓名/别名 + 模糊建档的名字**灌进 `segmenter.setExtraWords()`。

用户词的词频给 **100 万**（不是 `MAX_SAFE_INTEGER`）——给最大值会把「周末」也拆成「周|末」，因为一个词压过两个词。100 万既能让「老陈」压过「老+陈」，又不会压过真正的复合词。

### 3. 两种口径分开

| 匹配对象 | 判定方式 | 原因 |
|---|---|---|
| **姓名／别名** | 按**词边界**（分词） | 中文没有分隔符，必须靠词表判边界 |
| **索引词** | 保持**字串包含** | 它们是自由短语（「旧港码头」「那场雨」），不在任何词表里，分词反而全漏 |

### 4. 退役的东西

- `HONORIFIC` 称谓表；
- `LEAD_IN` / `LEAD_FORM` / `TRAIL_IN` / `isBoundary` / `formPositions` / `hasHonorific` / `isStandalone` / `singleCharHit` / `weakHit`；
- `bareSingleName` 两套口径（玩家输入 / 正文现在同一套）；
- **「单字姓名必须配 ≥2 字别名」的硬规矩** → 降为建议（分词能判边界了）。

### 5. 保留的东西

- **回头测试**（[ADR 0031](0031-回头测试与沉降.md)）**一个字不动**——它是建档前的判断，程序不代替它；
- 单字命中**仍只算弱证据**（`singleName`），永不冒充姓名／别名分——「陈老板」里的「陈」照样是独立词；
- 别名查撞（[ADR 0059](0059-别名查撞与单字名.md)）。

## 后果

- **收益**：不用维护称谓表；`周末`／`周围`／`周天子` 不再误命中，`周老板`／`周先生` 不再漏。
- **收益**：玩家输入与正文同一口径，少一类 bug。
- **代价**：仓库 +1.34MB 数据；启动时多读一次文件（实测 4ms）。
- **代价**：**依赖用户词典**——接线处忘了灌人名，多字人名会全漏。已在 `runWriteback` 与召回注入两处调用 `syncUserWords`。
- **边界**：分词只解决"词内包含"，不解决"同形异义"（有人叫「小满」，正文写"今日小满"照样命中）和代称（「那老家伙」）。

## 被否决的方案

- **继续扩称谓表**：永远列不完，且只是猜得更准。
- **引入 npm 分词包**：违反零运行时依赖。
- **索引词也走分词**：自由短语不在词表里，会大面积漏。
- **用户词典给 `MAX_SAFE_INTEGER`**：会把复合词拆碎（实测「周末」被拆）。

## 待定

- 词表要不要按卡切换（古风卡 vs 现代卡用词不同）。
- 「今日小满」这类同形异义要不要单独处理（现在无解）。
