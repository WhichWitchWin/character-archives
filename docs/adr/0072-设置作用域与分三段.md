# 0072 设置按三种作用域存，设置页分三段可折叠

- **状态**：有效
- **日期**：2026-11-03
- **相关**：[ADR 0054](0054-配置存储位置.md)（原本定的是"按卡分区"）、[ADR 0070](0070-预设表界面.md)

## 背景

设置项**全都**存在整局数据 `state.settings` 里——**换一局（同一个存档）就全部回到默认值**。

这不合理：「召回预算多少」「提示写多细」「调试开不开」这些跟"这局发生了什么"毫无关系，却要每局重设一遍。

而且 ADR 0054 早就定了「按卡分区」，实现却偏离成了按局。

## 决定

### 1. 三种作用域

| 作用域 | 谁共用 | 存哪 |
|---|---|---|
| **global 全局级** | 所有局、所有卡 | 插件数据 `settings`（全局一份） |
| **card 人物卡级** | 同一张卡的多个存档 | 插件数据 `settingsByCard[cardKey]` |
| **game 会话级** | 一个存档一份 | 整局数据 `state.settings` |

### 2. 哪些组归哪边

| 作用域 | 组 |
|---|---|
| **全局级** | 档案写入方式、召回、条目预设库/MVU、可见性、关键度、容量、提示、调试 |
| **人物卡级** | 首次离场、信度 |
| **会话级** | 本局勾选哪些栏目 |

**「首次离场」「信度」按卡的理由**：这两组是**这张卡的设定**——离场节奏跟卡的叙事节奏有关，信度体系跟卡的 MVU 字段结构绑定。

**「勾选哪些栏目」按局的理由**：它决定**这一局的档案长什么样**，跟着局走最自然（预设表本身也是按局的，ADR 0070）。

### 3. 设置页分三段，可折叠

```
▾ 全局级    8 组
  ▸ 人物卡级   2 组
  ▸ 会话级     1 组
```

- 每段点标题**整段收起／展开**；
- 默认：全局级展开，卡级和会话级收起（别一打开就铺满屏）；
- 段标题右边标「N 组」。

### 4. 新增一种控件类型：`codes`（多选）

「勾选哪些栏目」不是开关也不是数字，是**一排可多选的条目**——每个栏目一个按钮，存成条目码数组。

`coerce` 加了 `codes` 分支（数组或逗号分隔字符串都认）。

## 后果

- **收益**：常用设置（预算、提示、调试）**设一次就长期有效**；换存档不用重设。
- **收益**：设置页不再铺满屏，按作用域收起来更清爽。
- **代价**：同一张卡的两个存档，**「首次离场」「信度」是共用的**——想给某个存档单独调，得改作用域（暂不支持）。
- **代价**：老的按局设置**不会自动迁移**——升级后全局级/卡级的设置回到默认值，需要重设一次（会话级的老设置还在原处）。

## 实现要点

- `settings.js` 加 `SCOPE`（组 → 作用域）与 `splitSettings` / `mergeSettings`；
- `settingsView.js` 加 `GROUP_SCOPE` 与 `SCOPE_SECTIONS`，`describeSettings` 改成**按作用域分三段**返回；
- `index.mjs` 加 `readScopedSettings` / `writeScopedSettings`，**所有**读设置的地方都改走它（原来有 7 处直接读 `state.settings`）。
