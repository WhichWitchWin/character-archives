# 0046 召回接线：从快照到注入文本

- **状态**：有效
- **日期**：2026-11-02
- **supersedes**：[ADR 0018](0018-装配三步与完整召回延后.md) 里「两阶段装配」的实现口径（改回文档写的**三步**）

## 背景

到这一步为止，纯逻辑模块都写完了（匹配、打分、简版、冷却、快照……），但**插件装上不干活**：

- `index.mjs` 只做了「结算时记一笔 meta」和「返回摘要」；
- 召回注入（`turnSection`）根本没注册；
- 装配层 `compose.js` 还是**两阶段**（简单 → 完整），而设计稿 §7.3 早就改成**三步**（简单 → 详细 → 提示）。

也就是说：**零件齐了，没装起来。**

## 决定

### 1. 新增两个纯逻辑模块

| 模块 | 管什么 |
|---|---|
| `lib/render.js` | 详细档的值行（`· 条目名：值 —— 来源（时间）`）＋ 整段抬头（`【人物一致性参考 · 视角：X】`） |
| `lib/recallPipeline.js` | **筛人 → 打分 → 装配 → 出文本**，一次调用出整段 |

`index.mjs` 只留胶水：读整局数据 → 读快照 → 调 `buildRecall()` → 交给 `turnSection`。

### 2. `compose.js` 从两阶段改成三步

| 步 | 做什么 |
|---|---|
| ① 保底 | **非提示档**按分数各放一行简单，装不下跳过 |
| ② 加厚 | 用剩余预算把够详细分的升成详细档，装不下停在简单 |
| ③ 填提示 | 还有预算才塞**提示档**——最低优先，塞不下就算了 |

输出仍按分数顺序（提示档也回到它该在的位置）。

### 3. 召回管道的筛选顺序

```
① 状态必须是「离场」
② 姓名位非空            （ADR 0044）
③ 眼睛没闭上            （👁）
④ 至少一条勾选条目有值  （ADR 0044）
⑤ 冷却未到期            （人物级）
⑥ 打分 → 分档 → 装配
```

前五条任一不满足就**不进池**；进池后按分数排序，`none` 档丢掉。

### 4. 出错绝不拖累正文

`turnSection` 的回调整个包在 try/catch 里：**任何异常都只让这一段缺席**，返回空串，正文照常生成。

另外单段超 8000 字时**整段不发**——宁可这轮没有资料，也不要塞半截。

## 这一版的已知降级（重要）

| 降级 | 原因 | 补的时间 |
|---|---|---|
| **线索匹配只吃 `flags.lastHits`** | 索引词缓存还没实现（ADR 0021 说存 `savePluginData`），所以本轮玩家输入只做姓名/别名匹配，命中不了索引词 | 写回侧一起做 |
| **冷却只查人物级** | 条目级/值级冷却还在改（值级 + 覆盖迁移） | 写回侧一起做 |
| **详细档不按「本轮相关」排** | 依赖索引词缓存，同上；现在按预设顺序 | 同上 |
| **勾选条目没配过时默认全选** | 否则 v0.1 一个都不召回，等于没接 | 面板做出来后换成真实配置 |
| **关键度用「非空条目数」代理** | M3 的临时口径（§6） | M4-3 |

## 后果

- **收益**：插件第一次真的干活——正文生成前会看到「人物一致性参考」那一段。
- **收益**：`index.mjs` 保持极薄，逻辑全在 `lib/` 里可单测。
- **代价**：上面五条降级都会让效果打折（尤其"线索命中不了"，等于只靠名字召回）。
- **边界**：快照不存在（还没存过）时直接返回空串，不报错。

## 被否决的方案

- **把逻辑写进 `index.mjs`**：那里碰 `ctx`，没法单测，违反项目「lib 纯逻辑」的规矩。
- **保持两阶段装配**：跟设计稿 §7.3 不符，提示档会被当成简单档一起挤预算。
- **超 8000 字截断**：截一半的资料比没有更糟——模型会以为档案就这么点。
- **出错时抛出**：会连累正文生成，插件不该有这种权力。
