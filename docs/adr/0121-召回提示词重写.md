# 0121 召回提示词重写：说清「谁记得」和「关于谁」

- **状态**：有效
- **日期**：2026-11-22
- **supersedes**：无（重写 [ADR 0080](adr/0080-召回抬头与来源标注.md) 定下的抬头措辞）

## 背景

2026-11-22 翻一局真实会话的**模型思考链**，看到它把注入读错了：

- 注入是 `▍老陈` / `· 演员：真（他自己确认过）`（真意：老陈记得「周可人是演员」）
- 模型的思考链原话：「**人物档案老陈：演员真**」——它读成了「老陈是演员」。

同一局里还有两种连带症状：

1. **反复自问「这条是谁知道的」**：查到 `▍周可人` / `· 演员：真` 之后，模型在思考链里两次纠结
   「这个『老师』是周可人知道的事，还是关于周可人自己的事？」——因为块头和人名都没说清是哪一层。
2. **把「没被念到」当成「不知道」**：某几轮它下结论「档案里找不到这个人」，于是让角色在正文里
   回答"不清楚"——而实际上只是那一轮没进召回（人在冷却里／离场），不是档案里没有。

旧提示词只说「是这局**已建档人物自己知道的事**」和「每条后面那截是**这个人对这件事的认知**」，
**没有一个字解释「▍名字」和「行首的人名」分别是什么**。模型只能猜，猜错了就写错。

## 决定

### 1. 抬头改成四句可操作的说明

```
【人物档案参考】
下面是**某个人记得的事**——不是客观真相，也不是剧情。
「▍名字」＝ 这是谁的记忆；每一行是**他记得的一件事**：
· 行首**没有**名字 → 说的是**他自己**（「· 演员：真」＝ 他认为自己是演员）
· 行首**有**名字 → 说的是**那个人**（「· 周可人 · 演员：真」＝ 他认为周可人是演员）
冒号后面是他的态度与来源：真＝他相信／假＝他不信／未定＝他拿不准；「他自己确认过」「听某人说的」是他凭什么这么想。
**没被列出来不等于他不知道**——只是这一轮没给；要确认就用查档案工具，别替他否认。
本局写作人称：{{VIEWPOINT}}
当前：{{STAMP}}

{{BLOCKS}}
```

四件事各解决一个坑：**块头是谁的记忆**（症状 1）、**行首有没有名字**（症状 1、2 的共同来源）、
**态度／来源怎么读**（原有内容，保留）、**没列出≠不知道**（症状 2）。

### 2. 字数从 194 涨到 315

多 121 字，默认预算 3000 时约占 4%。**认这个开销**：三段说明各对应一个真实发生过的误读，
少任何一段模型都会回到猜的状态。真要省，玩家可以自己在面板里删行。

### 3. 四处一起改（少一处就等于没改）

| 位置 | 作用 |
|---|---|
| `plugin/assets/recall-prompt.txt` | 运行期真正读的那份 |
| `plugin/prompt.js`（`RECALL_TEMPLATE`） | 读不到文件时的兜底，由 `scripts/sync-prompt.mjs` 生成 |
| `lib/promptTemplates.js` 的 `DEFAULT_TEMPLATES.recall` | 面板「恢复默认」用它覆盖 |
| 面板存档 `plugin-data/character-archives.json` 的 `prompts.recall` | **优先级最高**，它覆盖前三者 |

第四条最容易漏：面板存档存在时，改仓库里的文件一个字都不会生效。这次是备份后直接改的存档
（`backups/character-archives.panel-before-recall-20261122.json`），`prompts.system` 没动。

## 后果

- **收益**：模型不用再猜「谁记得」和「关于谁」；「没列出＝不知道」的误判有了明确反例。
- **代价**：每轮注入多 121 字；说明部分属于固定开销（不管召回到几个人都要付）。
- **边界**：提示词只管「怎么读」，不管「给什么」——给什么是 `recallEngine` 的闸门、打分、预算决定的。
- **边界**：玩家如果自己改过面板里的召回模板，这次改动**不会**覆盖他的版本（存档里已是他的文本，
  只有点「恢复默认」才会换成新版）。

## 被否决的方案

- **只修代码（加「关于谁」前缀）不改提示词**：前缀解决了"说的是谁"，但"块头是谁的记忆"和
  "没列出≠不知道"仍然靠猜——思考链证明这两处真的会猜错。
- **写更长、更详细的说明**：注入每轮都付，3000 字预算里 4% 已经不少；再长会挤掉实际内容。
- **只在「查档案」的返回里加说明**：自动召回那条路占比更大，而且两条路共用同一套措辞。
