# 0002 人物册与容量提示放在插件面板，不占「酒馆状态」页

- **状态**：已采纳
- **日期**：2026-10-31
- **supersedes**：设计稿 §3.5「提示的呈现方式」中「酒馆状态页的一节」一项

## 背景

设计稿 §3.5 规定：所有容量相关提示**不弹窗、不抢前台**，只通过两条通道呈现 ——

1. 侧栏角标：人物档案馆入口显示一个小红点／数字；
2. **「酒馆状态」页的一节**：按时间倒序列出全部记录。

M1 骨架按这条实现过 `registerStatusSection`，把「人物册」一节挂在酒馆状态页里。

## 决定

1. 人物册内容、容量提示、每轮动作记录，**全部放在插件自己的侧栏面板「NPC档案馆」内**，面板里单独留一块「记录」区。
2. **取消 `registerStatusSection`**，不再往「酒馆状态」页添加任何分节。
3. **保留「侧栏角标」**这一条通道（待 M2 做容量水位时一起实现）：不打开面板也能一眼看出"有事"。

## 后果

- 玩家不打开面板就看不到容量细节 —— 用面板入口的角标补足可见性，这是本决定能成立的前提。
- 插件对酒馆界面的侵入面更小：只注册一个侧栏面板，不往别人的页面里塞内容。
- 与设计稿 §3.5 不一致，以后读设计稿的人需要知道这一条已经改了（本条即为凭据）。
