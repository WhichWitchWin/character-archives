# 0114 条目眼与值眼：眼睛也分三层

- **状态**：有效
- **日期**：2026-11-14
- **supersedes**：无（补 [ADR 0037](0037-锁与眼睛解耦.md) 留下的「眼睛只有人物级」）

## 背景

[ADR 0037](0037-锁与眼睛解耦.md) 把 👁 定成「只管召回、不影响写入」，但当时只有**人物级**：
想让某一栏、某一条不被念，只能把整个人闭眼——代价是他别的栏目也一起不念了。

锁那边（[ADR 0113](0113-条目锁与值锁.md)）已经补到三层，眼还停在人物那一层。这次补齐。

## 决定

### 1. 三层眼，粒度与锁对齐

| 层 | 键 | 闭的是什么 |
|---|---|---|
| 人物 | `p7` | 这个人的指针全不注入（已有） |
| 条目 | `p7:a`（**谁的指针** × 栏目码） | 这个人在这一栏的指针不注入 |
| 值 | `12`（**命题 id**） | 这条命题不注入（谁记得都不念） |

存储都在整局数据：`flags.hidden`（已有）、`flags.hiddenEntries`、`flags.hiddenClaims`。
**不写快照**——回退时眼保持原样，与锁同一套。

### 2. 为什么条目眼按「谁的指针」，值眼按「命题」

这是两层唯一不一致的地方，故意的：

- **条目眼**：召回注入的单位是「某人 · 栏目：他记得的事」，而人物眼本来就是按**持有者**判的
  （`hidden.has(personId)`）。条目眼跟着这个口径，才不会出现「闭了老陈的「职业」栏，
  却把李四记得的同一句话念出来」这种说不清的状态。
- **值眼**：命题在结构上全局只有一份（[ADR 0081](0081-信度改成事实加指针-提案.md)）。玩家在
  「他是什么样」或「他的认知」任一处给一条命题闭眼，期望是「**这句话**别被念」，
  而不是「某个人别念它」——所以按命题 id 判，全局生效。

### 3. 不允许「子比父宽」

人物闭眼时，他下面的条目与值**一律算隐藏**。理由同锁（ADR 0113）：面板上不能出现
「人物闭着眼、某栏却显示睁眼」——玩家会以为那栏还在念，实际模型看不见。

### 4. 只管召回，别的一概不动

- **不注入**：召回引擎的「闸 2」从按人扩成按人 + 条目 + 值；
- **照常写入**：眼与写入无关（那是锁的职责）；
- **面板照常编辑**：玩家自己改不受限；
- **改状态照常**；
- **查认知照常**：那是面板翻阅，不是注入（ADR 0089 的三条入口语义不变）。

### 5. 与锁正交

锁＝不写、眼＝不念。四种组合都合法（ADR 0037 的人物级口径直接下沉到条目/值层）：

| 🔒 | 👁 | 效果 |
|---|---|---|
| 解锁 | 睁眼 | 正常 |
| 锁上 | 睁眼 | 照常念，模型不能改 |
| 解锁 | 闭眼 | 不念，剧情提到时照记 |
| 锁上 | 闭眼 | 既不念也不写 |

### 6. 哪些入口受眼管

眼睛的作用是「别在档案参考里提醒它」，不是「模型绝对看不见」。所以只有**注入**这条路上生效：

| 入口 | 受不受 | 为什么 |
|---|---|---|
| 每轮自动召回 | **受** | 眼的本职 |
| 主角回场（自动给一次全量） | **受** | 它是自动行为，玩家当场没说过「偏要看」 |
| 面板「召回」（玩家点名） | **不受** | 玩家显式点了要看；点完却不注入，会被当成功能坏了 |
| 面板「查认知」 | **不受** | 恒全量是面板翻阅，本来就不进提示词（ADR 0089） |
| `archive_query`（模型自己问） | **不受** | 同上：查阅不是注入 |

**边界**：正文里本来提到的内容，模型照样读得到——眼只挡「档案参考」那一段。

## 后果

- **收益**：能精确控制「哪一栏、哪一条不给模型看」，不必为了藏一句话把整个人闭掉。
- **代价**：面板上每个人有三把小锁 + 三只眼睛，要能分清各自锁/闭的是哪一层
  （tooltip 写明「随人物隐藏」「随栏目隐藏」）。
- **边界**：**认知（指针级）的开关仍然不做**——用户 2026-11-14 明确定调「认知的不管」。
  也就是说，不能表达「只有他这么认为这件事、别念」这种粒度。

## 被否决的方案

- **条目眼按「命题的主人」判**：与人物眼的「按持有者」口径冲突，同一个键会出现两种含义。
- **值眼按「某人 × 命题」**：那等于指针级开关，用户明确不做（见上条边界）。
- **只做条目眼、不做值眼**：玩家最想藏的往往是具体一条（一句还没揭晓的真相），
  只到栏目层还是粗。
- **把眼和锁合并成一个「禁用」**：ADR 0037 已经否过（丢掉「只读」「只写」两种有用状态）。
