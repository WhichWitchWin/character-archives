# 0019 信度拆成两维：来源由模型判，真值只登证据

- **状态**：已采纳
- **日期**：2026-11-01
- **supersedes**：无（补齐设计稿 §5.1 里含混的「真/假」定义）

## 背景

信度这套东西**两头都堵**：

- **写入端**：没定义过模型该给什么信度、凭什么给。设计稿只在 §7.6 的校验项里提了一句"信度码合法"，提示词内容一个字都没有（§5.4 那句"关闭期间不注入信度提示词"反过来说明它本该存在）。
- **读取端**：`"0"`~`"9"`、`r42` 这些码定义了**格式**，但没定义**语义**——"真/假"到底是客观真相还是主角的判断？含混不清。

根因是一句话：**写正文的模型手里没有"真相"**。它不知道哪个 NPC 在撒谎，让它判真假等于让考生自己判卷。

## 决定

### 1. 信度 = 两个维度，不是一个分数

```
信度位 = 谁说的（来源） + 主角信不信（真值）
```

### 2. 来源：模型能判，交给模型

| 情形 | 来源 |
|---|---|
| 主角亲眼看到／亲口听到 | 用户 |
| 该角色自己说的（自报、辩解、吹牛） | 自述 |
| 别人说的、能指名 | 他述·某人（存 `r42`，解码成人名） |
| 别人说的、说不出是谁 | 他述·来源未知 |
| 状态机（MVU） | **模型不许写**，只能由映射表抄入 |

### 3. 真值：默认未定，只登证据

**首次写入一律「未定」**，只有一个例外：

> **第三人称叙述下，正文明确写了主角亲眼见到 → 「真」。**

其余情况（第一/第二人称、或第三人称但没写明亲见）**都留在「未定」**，不猜。

### 4. 「假」只有两个合法来源

1. **玩家手动标**（面板上改，或给角色打"惯于说谎"）；
2. **事后被正文推翻**——原来"未定"的自述值被主角亲眼戳穿 → 转"假"，**保留原值**（"他曾经这么骗我"是重要记忆，不能删）。

### 5. 模型不许改已有值的真值

要翻案用「判定第 N 条」动作：只改信度位，**不动值、不动轮次、不动 gt**。

（`gt` 一改，"这件事发生在永安二年"就变成"永安五年"了。）

### 6. 写入时把信度跟着值一起给（呼应 Q9）

```
【老陈·外貌】
1. 戴帽子（自述·未定·永安元年·春）
2. 左手两指旧伤（用户·真·永安二年·冬）
```

模型不看到"谁说的 + 现在信不信"，就会把同一个谎话重复登记一遍。

## 后果

- **收益**：不再要求模型回答它不知道的问题；"假"变成可追溯的（被证据推翻或玩家标定），不再是模型拍脑袋。
- **代价**：**绝大多数值初始都是「未定」**——档案看起来"全是没核实的说法"，需要玩家或后续剧情慢慢收紧。
- **边界**：**第一人称下的"我看见"不算真**（用户定的）。理由是第三人称里"主角"是明确的第三方，判断更可靠；第一人称容易和叙述者混同。
- **被否决的方案**：
  - *让模型判真假*：模型没有真相，只会编；
  - *默认给「真」*：把道听途说升格成事实，比"全是未定"更糟；
  - *不给信度只存值*：那就没法在召回时说"这是他自己说的"还是"你亲眼见的"。
