# ADR 0103 亲见不自动算真：态度按正文里他自己的表现判断

- **日期**：2026-11-06
- **状态**：已定并已实现
- **相关**：[ADR 0098](0098-认知模型四个旋钮.md)（认知四个旋钮，本条改它的默认值与「关掉」的含义）、[ADR 0020](0020-写入判断带上视角说明.md)（默认态度未定＋视角说明判亲见）、[ADR 0083](0083-写入流程-命题与指针.md)（命题＋指针）

## 背景

实际对局里主角的指针全是「自己 · 真」：

```
[0, "", "2026-05-20 07:23 早上"]   ← 0 = 真，"" = 自己
```

`TRUTH.TRUE = 0`、`SELF = ''`。模型报的原文是 `{谁:"小s", 来源:"自己", 态度:"真"}`——**来源写的是"自己"（不是"听沈清禾说的"）**，态度给「真」是照着当时的【认知口径】给的：`eyewitnessTrue` 开着，口径里写着「主角亲眼见到的，可以直接给『真』」。

问题在于：

- 「在北京地铁十号线车厢」（去向，他就在旁边）→ 亲见给真**合理**；
- 「爱试探陌生人的底细」（性格）→ 这是他**观察后推断**的，不是"确认过的说法"，给「真」就让面板显示得像既成事实；
- 而且默认开着，等于主角几乎**永远笃定**——玩家希望的是**由模型读正文判断他信不信**。

## 决定

1. **`cognition.eyewitnessTrue` 默认改成关**（`plugin/lib/settings.js`）；
2. **改「关掉」的含义**——这是关键，原来关掉＝一律按默认态度，现在关掉＝**按正文里他自己的表现判断**：

   > · 谁亲眼见到都不自动算「真」：按正文里他自己的表现判断——他明确信了、或这话本来就是他说的，给「真」；他明确不信、怀疑、觉得是假的，给「假」；看不出来，给「未定」。

   口径里的「未定」跟着 `defaultAttitude` 走（玩家可能把它设成真／假），所以是「看不出来，给『当前默认值』」；
3. 打开（`true`）时的那两条**保持不变**：主角亲见可直接给真、其他角色自己确认过的按自己判断给真／假；
4. 设置页文案跟着改：标签「亲眼见到就当作『真』」，说明写清默认关 + 关掉时按正文判断。

## 为什么

- **亲见 ≠ 相信**：看见一个人做了什么事，和"我确认他是什么性格"之间隔着推断。让态度默认落在「未定」，面板才不会把推测显示成事实；
- **关掉不能等于关闭判断**：原来的「一律按默认态度」会让模型彻底不做判断，主角变成"什么都不知道"，比过度自信更糟；
- **正文里有的是线索**：他信了会应、会跟着走；他不信会质疑、会否认。这些比"是不是亲见"更贴近玩家想要的语义。

## 代价与边界

- **默认值只管新局与「恢复默认」**：已有存档里存过 `cognition.eyewitnessTrue` 的按存的来（玩家自己关过就已经是关）；
- **依赖模型读正文**：模型可能仍然过度给真，也可能过度给未定——**未实测**，要跑几轮看面板里的态度分布；
- **「说法相反」那条不受影响**：系统提示词里「别人说的跟他自己知道的相反 → 写相反态度」仍在，真假不会因此废掉；
- **守卫**：`tests/cognitionSettings.test.mjs`（默认值与叠默认）、`tests/followup.test.mjs`（关掉后的三句口径）已同步更新，全量 753 全过。
