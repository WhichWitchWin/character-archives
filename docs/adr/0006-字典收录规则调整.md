# 0006 字典收录规则：长句无条件收、短句首次就收

- **状态**：已采纳
- **日期**：2026-10-31
- **supersedes**：设计稿 §4.3 收录规则表中「4～8 个汉字第二次出现才收录」与「含数字的混合串不收录（不限长度）」两条

## 背景

原规则有两条在实践中站不住：

**① 「含数字就不收」误杀长句。**
规则对「三天后」「27岁」是合理的，但它按"句子含数字字符"来判断，而中文数字「一 / 两 / 十 / 千 / 万」在叙事里极常见：

- 「他**一**个人守在旧港码头边上」（13 字）
- 「**两**人对视了一眼」（8 字）
- 「码头边上**十**几个搬夫」（10 字）

这些正是最该进字典的长句 —— 快照每轮存一份完整人物册，一个值写进去后会在之后每一份快照里重复出现，收进字典的收益随快照份数线性增长。为了一两个数字字符放弃整句，不划算。

顺带发现：原规则举的两个例子（「三天后」3 字、「27岁」2 字）**本来就低于 4 个汉字门槛**，也就是说这条规则对它自己举的例子根本不起作用。

**② 「第二次出现才收录」几乎永远不生效。**
它靠一个内存计数器数出现次数，而计数器不落盘。每轮重新打开字典时计数归零，于是"第二次"永远等不到。要让它生效就得把计数存进整局数据 —— 为一条边际收益很小的规则加一份持久状态，不值。

## 决定

| 汉字数 | 行为 |
|---|---|
| **超过 8 个** | **一律收录**，含数字也收 |
| **4～8 个** | 含数字（阿拉伯或中文数字）→ 不收；否则**首次出现就收** |
| 少于 4 个 | 不收 |
| 人名 / 地名 / MVU 值 / 纯英文 / 纯标点 / 空白 | 不收（不变） |

- 取消「第二次出现」这套计数，字典模块不再持有任何内存计数状态；
- 设计稿举例的「三天后」「27岁」行为不变（都低于 4 个汉字）。

## 后果

- **收益**：长句不再被误杀；字典模块少了一份内存状态；规则可一句话说清。
- **代价**：4～8 个汉字的词首次出现就占槽位，字典会比原来略微膨胀（每个短词约 12～24 字节），整局数据 256 KB 里可忽略。
- **被否决的方案**：
  - *只把阿拉伯数字算数字*：会让「三个月后」这类时间短语进字典，与"不收数量/时间短语"的意图冲突。
  - *保留二次出现规则并把计数落盘*：多一份持久状态，换来的只是少收几个短词。
  - *按「数字 + 量词」精确判断*：仍然误伤「一个人」，且正则越来越复杂。
