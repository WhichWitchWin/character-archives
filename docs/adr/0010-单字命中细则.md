# 0010 单字命中的落地细则：统一弱证据 + 三条识别通道

- **状态**：已采纳（「引号/括号通道」仍待拍板）
- **日期**：2026-11-01
- **supersedes**：无。本 ADR **不推翻**设计稿 §7.10 的「单字名保护」，而是把它的落地细则写清楚。

## 背景

A1 文本匹配落地时，设计稿只有一句「单字名命中 0.6；只靠单字名命中 → 最高只到候选」，**没说哪些单字算命中**——而这恰恰是全部难度所在：

- 中文不切词。「周」既可能是姓氏简称，也可能是「周末／这周／周朝／周会」的零件；
- RP 里的单字名常常是意象字（溯／决／枭）或代号（生／死／景／伤），**它们同样都是高频字**；
- 玩家输入里确实会用单字喊人（「周，你怎么看」）。

开发中试过一版「玩家输入里独立成词 → 1.0」，被对抗测例撞穿：

| 输入 | 旧行为 | 原因 |
|---|---|---|
| 这周要加班 | 1.0（满分召回） | 「这」在前界表、「要」在后界表，单字正好夹在中间 |
| 周朝的制度 | 1.0 | 「朝」被塞进了后界表 |
| 周会改到周三了 | 1.0 | 「会」被塞进了后界表 |
| 周氏集团上市了 | 1.0 | 后缀「氏」几乎恒真 |

根因是把**内容词**（会／朝／都／要）当成了边界标记。**内容词是开集，永远补不完；语气词、否定词、疑问词才是闭集。**

## 决定

### 1. 单字命中统一 0.6，永不置 `name`／`alias`

只置 `singleName`。配合 `recall.tierOf` 的 `weakOnly`，单字永远最多到「候选／提示」档——**噪声上限从"满分召回"降到"一行提示"**。

### 2. 正文侧不认裸单字

正文只认称谓形态。「周末」「周天子」「周朝」在正文里彻底不会中招。

### 3. 称谓表写成数据（闭集，可换预设）

- 前缀：老／小／阿
- 后缀：老板／姑娘／先生／总／哥／姐／叔

**不收「氏」**：周氏集团／周氏一族会被当成在叫周氏，误伤比收益大。

### 4. 玩家输入的裸单字：闭集边界

- **前界**：句首、标点、介词/连词/助词/量词、少量高频动词
- **后界**：句尾、标点、**语气词 + 否定词 + 疑问词**

两条硬约束：

- **内容词一律不进表**（会／朝／都／要／的／了）——这是上一版被撞穿的直接原因；
- **指示代词「这／那」和序数「上／下／每／一／两」不进前界**——它们和「周」组成时间词（这周、上周、每周）。

### 5. 引号/括号通道（待拍板）

被 「」『』《》〈〉【】〔〕〖〗 ()（） [] 包住的单字 → 0.6。

理由：**中文写单字名本来就要加引号**（不加读者也分不清），作者替我们消了歧；「生死景伤」这类代号型名字在正文里就能靠这条召回。

### 6. 线索词

单字线索词（酒／刀／雨）直接丢弃；同一词去重；**子串合并**（「旧港」与「旧港码头」算同一条）；大小写合并。

## 后果

- **收益**：单字噪声的上限降为一行提示；「周末／周朝／周会／周氏集团」不再误伤；与设计稿 §7.10 一致；生死景伤这类单字角色仍有三条路被认出。
- **代价**：玩家明确喊「周」时不再强命中，只给提示（交给正文模型判断）；正文里**不带引号、不带称谓的裸单字名召回不了**。
- **边界**：闭集表之外的说法仍可能漏认。漏认只是少召回，不会误伤。
- **被否决的方案**：
  - *独立成词 → 1.0*：对抗测试撞穿，且违反 §7.10 的单字名保护；
  - *继续扩内容词表*：开集，补不完，越补越漏；
  - *从源头禁止单字名*：RP 里「生死景伤」这种代号名很合理，不能禁。
