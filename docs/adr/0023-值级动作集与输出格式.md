# 0023 值级动作集与输出格式

- **状态**：已采纳
- **日期**：2026-11-01
- **supersedes**：ADR 0019 里「首次写入可给真」那条例外（改为**只能由判定设置**）

## 背景

设计稿 §7.6 只列了四种动作（新增／覆盖／删除／无变化），既没有"改真假"的入口，也没有任何输出格式。模型想说清楚"我要改什么"，必须有一套固定按钮和固定表格。

## 决定

### 1. 五个动作

| 动作 | 作用 | 必填 |
|---|---|---|
| **新增** | 给栏目加一条值 | 栏目、值、来源 |
| **覆盖** | 改第 N 条的内容（**同一件事的修正**） | 栏目、序号、值、来源 |
| **删除** | 去掉第 N 条 | 栏目、序号 |
| **判定** | **只改真假**，不动内容 | 栏目 ＋（序号 **或** 值）＋ 真值 |
| **无变化** | 不动 | — |

可选字段：`来源者`（仅他述时）、`线索`（0～2 个，新增/覆盖）。

### 2. 真值只能由「判定」设置

- **新增**：**不带真值字段**，一律落 `未定`；
- **覆盖**：**不带真值字段**，且**重置为 `未定`**（内容变了，旧判断不再适用——否则"真"会被贴到完全不同的内容上）；
- **判定**：模型侧**唯一**能改真值的入口，也是唯一能设 `假` 的地方。

> 这一条取代 ADR 0019 里"第三人称主角亲见 → 首次写入直接给真"的例外：现在主角亲见也要走判定。视角说明（ADR 0020）继续保留——它是**判定**的依据。

### 3. 两条轴互不打架（判定可以单独拎出来）

冲突检查**按维度分**，不是"一个值只能一个动作"：

| 轴 | 限制 |
|---|---|
| **内容轴** | 同一 `(栏目, 序号)` 最多一个「覆盖」或「删除」 |
| **信度轴** | 同一 `(栏目, 序号)` 最多一个「判定」 |
| **两轴之间** | **可以并存**：`覆盖第 2 条` ＋ `判定第 2 条`（先改内容、再改真假） |

无意义组合直接丢：**「删除」＋「判定」同一条** → 判定丢弃。

因为新增的值还没有序号，所以"刚加的值要改真假"→ **用「判定：栏目＋值」按内容指认**。

### 4. 输出格式

纯 JSON 数组，不要解释、不要代码块；没有变化返回 `[]`。

```json
[
  { "动作": "新增", "栏目": "当前处境", "值": "在旧港码头养伤",
    "来源": "自述", "线索": ["旧港码头"] },

  { "动作": "覆盖", "栏目": "身份", "序号": 2, "值": "南洋商行二掌柜",
    "来源": "他述", "来源者": "林昭", "线索": ["南洋商行"] },

  { "动作": "判定", "栏目": "身份", "值": "南洋商行二掌柜", "真值": "假" },

  { "动作": "删除", "栏目": "身份", "序号": 3 }
]
```

### 5. 覆盖的两条纪律

1. **覆盖只用于"同一件事的修正"**（`账房` → `旧港码头的账房`）；换成另一件事必须「删除 + 新增」，否则时间、历史、信度全糊在一起；
2. **程序兜一道**：新值若**连旧值的一个字都没有**（零字重叠）→ **拒绝这条覆盖**并记日志。误拒的代价只是这一轮没更新。

### 6. 精确去重（§7.8 第一层）

归一化（去空格、全半角统一、去句末标点、英文大小写、数字按数值比）后：

| 情况 | 处理 |
|---|---|
| 新增的值与本栏目已有值相同 | 视为「无变化」，不新增 |
| **覆盖后与另一条已有值相同** | **拒绝该覆盖**（正确做法是"删除"那条重复的） |

## 后果

- **收益**：模型有了确定的按钮和表格；真假只有一个入口，日志可追溯；覆盖不会把旧证据贴到新内容上。
- **代价**：模型要多发一条判定才能标真假（同一次调用，不额外花钱）；覆盖频率增加时真值会被重置。
- **边界**：程序只能挡格式和字面错误，**语义对不对仍取决于提示词与模型能力**；兜底靠锁定、快照回退与面板可见。
- **被否决的方案**：
  - *写入时直接给真值*：模型会顺手改真假，且"真"会跟着覆盖跑到新内容上；
  - *覆盖继承旧真值*：会把"账房（真）"的证据贴到"赌场打手"上；
  - *一个值只允许一个动作*：导致"改内容又改真假"做不到，判定被迫塞进内容动作里。
