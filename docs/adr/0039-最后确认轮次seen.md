# 0039 最后确认轮次：`flags.seen`

- **状态**：有效
- **日期**：2026-11-02
- **supersedes**：[ADR 0025](0025-离场记录取代在场名单.md) 里「去掉 `anchors`，只保留离场记录」这一条——`anchors` 的部分作用要请回来；但**只请回轮次，不请回 `gt`**

## 背景

### 1. 这个数原本存在

[ADR 0005](0005-时间只记录不解析.md) 第三节有「在场名单 `anchors`」：

```js
anchors: { p7: { turn: 20, gt: "三年五月十二日" }, … }
```

每轮覆盖为他最后一次出现的轮次与当时的 `gt`。原话说得很直白：

> 「最后一次出现是哪一轮」**只有事后才知道**，不能等到判定时再记。

### 2. 后来被删了，理由当时成立

[ADR 0025](0025-离场记录取代在场名单.md) 把它换成只在「在场→离场」那一刻写一条的 `flags.left`：

> 保留 `anchors`：**建档提前后它只剩「离场时间」一个用途**，为这点功能养一张滚动表不划算。

当时确实如此——离场时间用 `flags.left.gt` 就够了。

### 3. 但这个前提已经不成立了

后来加了两个机制，**两个都要这个数**：

| 机制 | 需要什么 |
|---|---|
| **模糊离场**（gap ≥ 3 轮） | 他最后一次被提到是第几轮 |
| **沉降**（gap ≥ 20 轮） | 同上，同一个数 |

而设计稿已经把它们写下去了：

```
gap = 当前轮次 − 最后确认轮次
```

**可这个「最后确认轮次」从来没定义过存在哪。** 设计稿引用了一个不存在的数据——这是实打实的洞，不是文字游戏。

### 4. 为什么不能拿别的凑

- **用 `flags.left`**：它只在「在场→离场」那一刻写。判离场**之前**它根本还不存在——拿它数 gap 等于**先有鸡才有蛋**；
- **用值的轮次**：值只在"被写"的时候才有轮次。人出现了、但没产生新值（比如只是打了个招呼），轮次不会前进 → **误判离场**；
- **每轮重扫历史正文**：读不到（正文只在当轮拿得到）。

## 决定

### 1. 新增 `flags.seen`，整局数据

```js
flags.seen = { p7: 20, p12: 35 }   // 人物编号 → 最后一次被提到的轮次
```

- **每人一个整数**，约 8 字节；200 人约 2 KB，整局数据 256 KB 里可忽略；
- **只存轮次，不存 `gt`**——离场时间仍然归 `flags.left.gt`，两处真相不允许重复。

### 2. 谁写

程序在 `onTurnSettled` 的**同一次正文扫描**里，命中谁就把 `seen[编号]` 刷成当前轮。这次扫描同时产出：

- 【本轮提到的人】＋状态（[ADR 0032](0032-判定素材带状态.md)）
- 模糊建档的"本轮露脸"名单（[ADR 0036](0036-模糊建档表的存储与扫描.md)）
- `flags.seen` 的刷新

**另外三处也算「确认」，同样刷新**：写入新值、玩家手动编辑、点★。

### 3. 怎么用

```
gap = 当前轮 − flags.seen[编号]
```

- 模糊离场：`gap ≥ N` 且现场名单里没他 → 判离场；
- 沉降：`gap ≥ 沉降轮数` 且非★ → 沉底。

### 4. 没有记录怎么办

刚建档、还没被扫到过的人没有这条记录 → 视为 `gap = 0`（不判），下一轮扫描就会补上。

### 5. 回退：截到当前轮，不删

回退到第 10 轮，而 `seen` 里记着 15 → 那是**未来**的轮次，gap 会算成负数。

处理：**把大于当前轮的值截到当前轮**。不删——删了会冒出一堆"没有记录"的缺失状态，反而要额外处理。

## 后果

- **收益**：模糊离场和沉降终于有数据可用，两个机制从"纸上公式"变成可实现。
- **收益**：每人一个整数，比原来的 `{turn, gt}`（约 30 字节）还小。
- **代价**：多一张表要维护；回退要截断一次。
- **边界**：只管**已建档人物**（有编号）。模糊建档的人用另一张表 `draft`（`{姓名: 入表轮次}`，[ADR 0036](0036-模糊建档表的存储与扫描.md)）。

## 被否决的方案

- **恢复完整 `anchors`（连 `gt` 一起）**：`gt` 已经归 `flags.left`，再存一份就是两处真相，迟早对不上。
- **用 `flags.left` 算 gap**：先有鸡才有蛋。
- **用值的轮次算**：人出现但没写值时轮次不前进，会误判离场。
- **每轮重扫历史正文**：正文只在当轮拿得到，历史读不了。

## 待定

- **代称仍会漏**：正文写"那老家伙"时程序匹配不到，`seen` 不刷新 → gap 照涨 → 3 轮后可能误判离场。目前没有补丁（放宽 N 只能降低概率，不能解决）。
- 玩家手动编辑、点★ 刷新 `seen` 时统一取"当前游戏轮次"——如果玩家在非结算时机操作，这个轮次是否总是可用，等接线时验证。
