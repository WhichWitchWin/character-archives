# 决策记录（ADR）索引

## 怎么用

- **写代码前有疑问** → 先在这里按"一句话"找对应记录，别重新推演。
- **想推翻某个旧结论** → 新增一份 ADR，标 `supersedes: ADR NNNN 中「某条」`，**旧文件正文保留不动**。
- **做了新决策** → 按六段模板写（状态·日期·supersedes／背景／决定／后果／被否决的方案／待定），然后在本索引加一行，再改设计稿对应小节并标 `见 ADR NNNN`。
