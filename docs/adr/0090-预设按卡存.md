# ADR 0090 · 预设按「卡」存，不按局

- **日期**：2026-11-04
- **状态**：已定并已实现
- **相关**：[ADR 0008](0008-条目定义的存放位置.md)、[ADR 0072](0072-设置作用域与分三段.md)、[ADR 0070](0070-预设表界面.md)

## 背景

ADR 0008 定的三层是：预设表（跨局，插件数据）／MVU 映射表（跨局跟卡绑）／该局条目定义（整局数据）。**前两层从来没落过实现**，实际是：

- 条目定义、勾选召回、唯一值、MVU 映射**全存在整局数据**里；
- 每个新局都从代码常量 `buildPresetDefinitions()` 现生成一份默认；
- 玩家在 A 局改好的栏目配置，**B 局一点都继承不到**。

## 决定

**预设按「卡」存**：同一张卡的多个存档共用一份；换卡才换一套。

| 数据 | 存哪 |
|---|---|
| 条目定义（名字／描述／唯一／必带／约定／可检索） | 插件数据 `presetsByCard[cardKey].entries` |
| 勾选召回（`checkedCodes`） | 同上 `.checkedCodes` |
| 唯一值（`uniqueCodes`） | 同上 `.uniqueCodes` |
| MVU 映射勾选（`mvuChecklist`） | 同上 `.mvuChecklist` |

- **整局数据不再存这四项**：`saveGameState` 写盘前把它们摘出来，写到卡级，再存整局数据。
- **`loadGameState` 读的时候覆盖回来**：卡级没有就沿用 `createGameState()` 的默认预设。
- 没有卡 id（极少见）时跳过写卡级，不往全局塞。

## 为什么

- 预设是"这张卡怎么玩"的配置，同一张卡的不同存档本来就该一致；按局存等于每次重来一遍。
- 不选"全局"：不同卡的栏目体系可以完全不同（一个武侠、一个科幻），全局混在一起会互相污染。

## 不做的

- **不做旧数据迁移**：一版没发过，整局数据里残留的 `entries` 字段读的时候会被卡级覆盖／忽略。
- ADR 0008 里的"跨局预设表（只存文字名）"仍不做——按卡存已经够用；将来要做"预设分享"再按 ROADMAP P10 重新设计。
