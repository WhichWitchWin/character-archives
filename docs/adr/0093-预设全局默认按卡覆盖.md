# ADR 0093 · 预设改成「全局默认 + 按卡覆盖」

- **日期**：2026-11-05
- **状态**：已定并已实现
- **supersedes**：[ADR 0090](0090-预设按卡存.md) 里「预设按卡存」这一条（条目定义／勾选／MVU 勾选表存 `presetsByCard[cardKey]`、每张卡各一份）
- **相关**：[ADR 0008](0008-条目定义的存放位置.md)、[ADR 0070](0070-预设表界面.md)

## 背景

[ADR 0090](0090-预设按卡存.md) 把预设从「整局数据」搬到了「按卡存」：`saveGameState` 每次保存都把 `entries` / `checkedCodes` / `mvuChecklist` 摘出来写进 `presetsByCard[cardKey]`，`loadGameState` 读时覆盖回来。

实际用下来有三个问题：

1. **跨卡不共享**：玩家在 A 卡调好的栏目描述，B 卡看不到——想统一就得每张卡改一遍；
2. **自动写、玩家没得选**：任何一次「存局」都会顺手写卡级，玩家分不清"我改了全局"还是"只改了这张卡"；
3. **没卡 id 时用局 id 兜底**：`cardKey ?? gameId`，于是没识别到卡 id 的局把预设写到了 `session-…` 名下——实测 11 个键里 10 个是局编号，其中好几个对应的局早就删了。

## 决定

**预设 = 全局默认 + 按卡可选覆盖。**

| 层 | 位置 | 什么时候写 |
|---|---|---|
| 全局（默认） | 插件数据 `presets` | 面板改预设，默认写这里 |
| 按卡（覆盖） | 插件数据 `presetsByCard[cardKey]` | **只有玩家点「按卡保存」**才写 |

**读取顺序**：卡级覆盖 → 全局预设 → 内置默认（`createGameState` 的 8 条通用预设）。

**`presets-save` 加 `scope`**：

- `'global'`（默认）：写全局；
- `'card'`：写这张卡（没有卡 id 直接报错，不再拿局 id 兜底）；
- `'clear-card'`：删掉这张卡的覆盖，回到全局。

**`saveGameState` 不再写卡级**：存局只存局数据（预设字段本来就从局数据里摘掉），写预设完全由 `presets-save` 决定。

**面板**：「预设」页显示「当前用：这张卡的覆盖 / 全局预设」，并给「按卡保存」「回到全局」两个按钮。

## 数据迁移（2026-11-05 已做）

- 先备份 `plugin-data/character-archives.json` 到 `backups/character-archives.json.20261105-presets-scope.bak`；
- 清掉 `presetsByCard` 里 10 个 `session-…` 垃圾键；
- 保留 `cards/改写权.json`（它作为那张卡的卡级覆盖继续生效）。

## 为什么

- **默认应该共享**：栏目定义是"这一套卡都该怎么记"，不是"这张卡专属"；按卡只是少数需要定制的场合；
- **写哪层要让玩家看得见**：以前自动写卡级，玩家以为改的是全局，换张卡发现没变；
- **局 id 不该冒充卡 id**：没有卡 id 就明说"不能按卡保存"，而不是悄悄写到一个永远对不上的键上。

## 被否决的方案

- **只改默认值、不管旧数据**：旧卡继续各用各的，等于这次改动对老玩家没感觉；
- **全清回全局**：会悄悄丢掉玩家在单张卡上的自定义；
- **给预设加版本号做自动迁移**：为了改一句描述引入一套版本机制，太重（这次用一次性脚本解决）。
