# 0071 面板里能直接打开数据文件夹

- **状态**：有效
- **日期**：2026-11-03
- **相关**：[ADR 0057](0057-自持文件存储.md)、[ADR 0058](0058-数据放插件数据区.md)

## 背景

数据散在**六个地方**（酒馆的指针、快照、整局数据、已删除、回收站、全局插件数据），路径还带四级兜底推断（ADR 0058）。玩家想自己看一眼、备份一下、或者删掉某个存档时，**得自己拼路径**。

## 决定

### 1. 两个新接口

| 接口 | 干什么 |
|---|---|
| `data-locations` | 返回所有存储位置的**真实绝对路径**＋存在与否＋一句话说明 |
| `open-folder` | 用**资源管理器**打开某个位置（Windows `explorer.exe` / macOS `open` / Linux `xdg-open`） |

### 2. 打开文件夹是**宿主侧**做的事

酒馆的插件 API **没有**"打开文件夹"这种能力（查过 `plugin-api.js` 全部方法，没有）。

但插件的**宿主侧跑在 Node 里**，可以直接 `spawn('explorer.exe', [dir])`（`detached: true` + `unref`，不阻塞）。

### 3. 只认白名单 key，不接受任意路径

`open-folder` 的 `target` 只能是固定几个 key（`store` / `snapshots` / `games` / `deleted` / `trash` / `pluginData`），**不接受传进来的任意路径**——免得面板被拿来乱开系统目录。

## 面板上的样子

在**设置页最下面**（跟着「调试」折叠区）：

```
数据位置
点右边「打开」直接用资源管理器打开这个文件夹。

插件自持数据（快照／整局数据／已删除／回收站）
C:\...\plugin-data\dsh-tavern-character-archives          [打开]
人物档案本体、预设表、MVU 映射都在这儿

快照（每轮一份人物册）
C:\...\snapshots\session-b07cac01-...                    [打开]
回退时读对应轮次那份

…
```

不存在的位置**按钮是灰的**（还没删过人、还没删过局，那些目录就不存在）。

## 后果

- **收益**：玩家不用再猜路径；改提示词、备份、清理都能直接点到。
- **代价**：跨平台要分别处理 `explorer`／`open`／`xdg-open`（各一行）。
- **边界**：只**打开文件夹**，不提供"在这里删除"之类的写操作——那些要走面板自己的功能。

## 附：一个容易踩的坑

从**源码目录**跑测试时，`pickDataRoot` 会落到第 ④ 级兜底（`<源码目录>/data`），路径和实际运行时的**不一样**。

真实路径只有在**从 tavern 安装位置加载**时才对（`<tavern data>/plugins/<名字>/` 往上两级）。所以验证路径时要按安装位置算，不能在源码目录里验。
