# 0063 三段提示词可编辑，全局存

- **状态**：有效
- **日期**：2026-11-02

## 背景

调提示词是高频动作：措辞一变，模型行为就变。写死在代码里只能等发版，所以要让玩家自己改。

三段：

| 段 | 用在哪 | 现状 |
|---|---|---|
| **系统提示词** | 子代理开局挂一次，管所有规则 | `docs/系统提示词.md` → `plugin/prompt.js` |
| **写入提示词** | 每轮第二次 followup 的素材骨架 | `followup.js` 里拼 |
| **召回提示词** | 注入**正文模型**的那一段 | `render.js` 里拼 |

## 决定

### 1. 模板化 + 占位符

| 段 | 占位符 |
|---|---|
| 系统 | `{{PERSON}}`（人称）、`{{PLAYER}}`（玩家称呼） |
| 写入 | `{{GT}}`（当前时间）、`{{PEOPLE}}`（程序生成的人头块） |
| 召回 | `{{VIEWPOINT}}`、`{{GT}}`、`{{LOC}}`、`{{STAMP}}`、`{{BLOCKS}}` |

**`{{STAMP}}` 是"时间 · 地点"拼好的整串**——地点为空时不会留下孤零零的 `·`。想自己拼可以用 `{{GT}}`／`{{LOC}}`。

**程序只填已知占位符，未知的原样保留**（写错名字不会把整段吞掉）。

### 2. 存在**全局**（插件数据）

`savePluginData().prompts = { system?, write?, recall? }`

理由：这三段是"我们怎么跟模型说话"，**换局换卡都该是同一套**。存整局/按卡都得每开一局重调一遍，反而烦。

### 3. 空串 = 恢复默认

玩家不用记住原文：清空后保存就回到内置默认。这样"调坏了"永远有退路。

### 4. 不编辑时，行为与改造前**逐字一致**

默认模板就是现在的输出。这条有测试守着。

### 5. 界面

面板多一个**「提示词」标签页**：三个多行输入框 + 每段的「保存」「恢复默认」，并直接列出该段可用的占位符。

改完**下一轮生效**（每轮读一次，不用重启）。

## 实现要点

- `lib/promptTemplates.js`：默认模板、`fillTemplate`、`resolveTemplates`。
- `fillTemplate` 用**逐字符扫描**，不用 `String.replace`——玩家写的值里可能带 `$&`、`$1` 这类 replace 特殊模式，会被当成替换语法吃掉（有测试）。
- 三段读取点：`runWriteback`（系统＋写入）、`turnSection`（召回）。

## 后果

- **收益**：措辞调整不用发版；出问题能立刻回退（清空即默认）。
- **收益**：占位符明示，玩家知道哪些是程序填的、哪些是自己写的。
- **代价**：玩家可能改出跑不通的模板（比如删掉 `{{BLOCKS}}`，召回就只剩抬头）。**没有做校验**——他是自己在调，看得见效果。
- **边界**：改的是"外壳与规则"；**值的格式、素材里的人头块仍由程序生成**，避免把结构化数据交给手写模板拼坏。

## 待定

- 要不要给模板加"另存为多套 / 命名"，方便在不同写法之间切换。
- 要不要在保存时提示"这段缺了必需占位符"（目前不校验）。
