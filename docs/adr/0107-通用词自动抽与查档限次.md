# ADR 0107 通用词由程序自动抽；索引词只管专名；查档每轮两次

- **日期**：2026-11-06
- **状态**：已定并已实现
- **相关**：[ADR 0077](0077-全局专名词库.md)（全局专名词库）、[ADR 0089](0089-召回装配预算打分必带条目地点.md)（召回打分）、[ADR 0021](0021-关联词的抽取规则.md)（索引词必须原文片段）、[ADR 0106](0106-撤回只写谁与约定回到固定提示词.md)（前一轮的撤回与约定调整）

## 背景

玩家提出一个具体场景：正文聊到「收银员」，希望想起「某人以前当收银员」，但现在的规则写着「不抽：通用职业（账房）」——职业词被挡在索引词之外，这条命题就召不回来。

讨论过三条路，前两条被否：

1. **给索引词加「类留空」**（让职业词能命中但不进词库）——玩家否：不想在四类之外再造模糊写法；
2. **给 `archive_query` 加「按关键词搜人」**——要改匹配逻辑、要处理"返回一串人模型还得再选"，成本高且不解决"根本想不起有这个人"。

## 决定

### 1. 通用词交给程序分词，模型只管专名

新增 `indexWords.js` 的 `autoWordsOf(text)`：拿项目已有的 jieba 分词器（`segment.js`，109758 词）把命题的**值**切开，只留 **2 字以上**的词，再挡掉一张泛词表。召回打分时，模型抽的索引词与自动词**合并判断**命中（+2 分不变）。

- **为什么只留 2 字以上就够**：实测虚词（在／的／了／他／但／当／被）在分词结果里**几乎全是单字**，一刀切掉即可，不必建完整停用词表；
- **为什么要泛词表**：真实验证里分词给出了「提出／来到／回来／看看／主动／提议／一圈／上午」这类词，几乎每条命题都有，一律给分等于把打分拉平。泛词表只挡高频功能词与空泛动作，**不挡名词**——「收银员」「超市」「药铺」必须能命中；
- **专名仍归模型**：`旧港码头` 会被切成 `旧/港/码头`（词典里没有），这类新专名靠模型抽的索引词补，并进全局词库。

**实测证据**（真实对局快照、泛词表加之前／之后）：

```
"小明在超市当收银员"        → ["超市","收银员"]              ← 玩家要的场景
"测试人的贴身随从"          → ["测试","随从"]（去掉「贴身」）
"随测试人来到公寓正门外"    → ["测试","公寓","门外"]（去掉「来到」）
"提议绕东边公园一圈再回来吃早饭" → ["东边","公园","早饭"]（去掉「提议／一圈／回来」）
"主动提出去问深蓝车的事"    → ["深蓝"]（去掉「主动／提出」）
```

效果验证：正文「柜台后的收银员抬头看了你一眼」→ 那条「在超市当收银员」得 2 分；同一条值在无关正文里得 0 分；不相关命题（「在药铺当学徒」）对同一段正文也得 0 分。

### 2. 索引词上限 0～2 → 0～3

长命题常有两个地名抽不进去（`约示例乙明天卯时码头见` 就有「卯时」「码头」两个候选）。只放宽上限，**「不抽」清单不动**（代词仍然不抽）。

### 3. `archive_query` 加使用时机，并限制每轮 2 次

- **描述**从一句「想不起某人知道什么，就查一下」扩写成「什么时候用／不用查／每轮最多 2 次」，解决"有工具但不太会用"；
- **限次**：新增纯逻辑模块 `lib/queryBudget.js`（`createQueryCounter`，账按「局＋轮」记，换轮自动清零），上限常量 `MAX_QUERY_PER_TURN = 2`。超限时回一句人话（「这一轮已经查过 2 次……先用已经拿到的信息写」），不静默失败。

## 一个顺带发现

**真实对局快照里，模型一条索引词都没抽**（两局共 11 条命题，`c[i][5]` 全是空）。所以索引词机制在实践中几乎没起作用——这也是为什么职业词、通用词的命中一直很弱。自动抽词补的正是这块。

## 代价与边界

- **性能**：召回时每条命题都要分词一次（`scorePointer` 里现算）。实测 11 条命题无感；命题上千条时可能需要缓存，**当前未做**；
- **误命中已压低但没消除**：泛词表是手工维护的，漏词就会漏挡。真跑几轮看召回是否变准是唯一可靠验证；
- **新专名首次仍可能丢**：`旧港码头` 第一次出现时切碎，靠模型抽的索引词兜；若模型也没抽，这条就召不回来；
- **`definitions` 参数**（上一轮遗留）仍未使用，本 ADR 不动；
- **未实测**：全部是软约束与打分变更，需要真跑；
- **要重启 DSH**：`index.mjs`（工具描述、限次、分词器注入）属宿主侧。

## 守卫
