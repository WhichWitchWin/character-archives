## 一、一句话：这是什么

DSH Tavern 的第三方插件 **NPC档案馆**（`dsh-tavern-npc-archives`）：把离场的非龙套 NPC 收进「人物册」，需要时按关键词召回注入正文；人物回场则冻结。

- 代码在 `plugin/`，**整个文件夹复制进酒馆 `plugins/` 就能跑**，无构建、零运行时依赖。
- 本地仓库只有 `main` 分支，**没有远程**，提交到今天为止。
- `npm test` = `node --test "tests/**/*.test.mjs"`，当前 **129 条全绿**，约 0.1 秒。

### 接口（宿主侧 `ctx.tavern`，apiVersion = 4）

| 接口 | 签名的关键点 |
|---|---|
| `turnSection({name,text,position?})` | `text` 可为**函数**，收到 `{gameId, turn, input}`（**input 是玩家本轮原文**）；每轮算一次、结果随该轮保存、重试沿用；出错或 **30 秒**跳过该段，正文照常；单段 ≤ **8000 字** |
| `onTurnSettled(handler)` | 收到 `{gameId,turn,textVersion,greeting,text,rawText,card,variables,settledAt}`（**variables 是结算后的，含 MVU 的 stat_data**）；「处理函数**不必等完成才返回**」＝ 不阻塞、也不保证跑完；同一 textVersion 只通知一次；**开场白不触发** |
| `settlementTask({name,title,phase,run})` | `phase` = `before`/`parallel`/`after`；`run` 收到同上内容 + `signal` + `runAgent`；**单任务 5 分钟**；**「下一轮会等它们跑完」**；每 textVersion 只跑一次；开场白不触发 |
| `runTask({gameId,prompt,tools?,signal?})` | 返回 `{text}`；**一次性会话**；自带人物卡/世界书/最近两轮剧情；`tools` ≤ 8 个、一次最多调 16 次；10 分钟超时 |
| `getTurn({gameId,turn})` | 含 `variables`；未结算的最新轮返回 `null` |
| `getTurnState({gameId})` | `{gameId,turn,textVersion,greeting,generating,settling,busy,settled}` |
| `getHistory({gameId,from,to})` | 一次最多 **50 轮**，返回 `[{turn,input,text,rawText}]` |
| `handle(name,handler)` | 参数 ≤ 256 KB，返回 ≤ **4 MB**；浏览器侧用 `tavernUi.callHost` 调 |
| `publishState({gameId,name,data})` | data ≤ 256 KB，只存最新一份，**只在内存** |
| `saveTurnData({gameId,turn,textVersion?,data})` | 每条 ≤ **64 KB**；每局 ≤ 2000 条 / 8 MB；**校验 textVersion**，过期写入被拒（`TAVERN_PLUGIN_STALE_VERSION`）；传 `data: null` 清除 |
| `readTurnData({gameId,turn})` | 读「该轮及之前**最近一份**」，返回 `{turn,textVersion,data}` 或 `null` |
| `saveGameData` / `readGameData` | 整局数据，≤ **256 KB**，不随回退变、分叉复制、删局清空 |
| `savePluginData` / `readPluginData` | 插件自己的数据，≤ 256 KB，**跨局**、跨设备（存在服务端） |
| `onTimelineChanged(handler)` | 收到 `{gameId,kind,turn?,textVersion?,fromGameId?}`；`kind` = `rollback`/`undo-rollback`/`regenerate`/`edit`/`fork`；**fork 时 gameId 是新游戏、fromGameId 是原游戏**；通知在变化保存**之后**发出 |
| `onGameRemoved(handler)` | 删局 |
| `versionSignal({gameId,turn,textVersion})` | 版本失效即中止 |
| `job()` / `member()` | **文档里不存在**（只在旧的 `plugin-design.md` 出现过，别用） |

## 八、红线与规矩（不遵守会返工）

1. **未得到明确「动手」指令前不写代码**，只给方案；**改文档前先给方案等确认**。
2. 用户**基本不懂技术**：大白话 + 生活化比喻，术语首次出现一句话解释；语气可爱，但**技术结论和风险不能为语气让步**。
3. **写档案一律用概念，不写具体条目名**：说「唯一值条目」而不是「姓名」（预设可换）。
4. **禁止 `rm` / `del` / `Remove-Item`**：要删一律移进回收站；动软链接前先审查。
5. **提交信息必须是 `type(scope): subject`**，否则被钩子拦（例：`feat(recall): 简版装配`）。
6. **测试先行**：这个项目里我已经两次"先写实现后补测试"，都被抓出问题；别学。
7. 设计稿 `docs/人物冷存档插件-设计稿.md` **由用户维护**，AI 只提方案。
8. 遇到规格矛盾**不要猜**，记进 ADR 的待定项或直接问。
