## 一、什么时候能召回（闸门）

| 条件 | 规则 |
|---|---|
| 时机 | 每轮正文生成**前**（`turnSection`） |
| 冷却 | 全量召回 → 冷却**整个人物**（默认 10 轮）；简版／连带 → 只冷却**给过的条目**；0 轮 = 无冷却 |
| 👁 可见性 | 眼睛闭上的人物**不召回** |
| 版本 | 快照 `v` 高于插件 → **拒绝召回**（只读展示） |
| 归档缓冲 | 刚归档的人物在一定轮数内不召回。**N = 召回冷却轮数**；**基准 = 最后一次在场轮**（不是判定轮、也不是写入轮） |

## 二、谁进候选（匹配）

| 信号 | 分值 |
|---|---|
| 姓名命中 | 1.0 |
| 别名命中 | 0.9 |
| 单字名命中 | 0.6（只在**玩家输入**里直接匹配；正文里只认「老周 / 周老板」这类称谓形式） |
| 关联线索 | 每条 0.5，递减累加（0.5 → 0.75 → 0.875…），封顶 1.0 |
| **一致性** | 本轮提到的其它东西 vs 档案登记的关联项：对上 1 条 0.4 / 2 条 0.7 / 3 条以上 1.0 |
| 单字名保护 | 只靠单字名命中 → 最高只到「候选」，不真召回 |

## 三、打分与分档

```
召回分 =（匹配 + 一致性 + 先验 + 时效）÷ 4
```

- **先验** = 关键度在全册中的分位（M3 暂用「非空条目数」代理，M4 换真算法）
- **时效** = `exp(-0.01 × 距上次更新的轮数)`

| 分数 | 给什么 |
|---|---|
| ≥ 0.80 | **全量**（完整人物书） |
| 0.50 ~ 0.80 | **简版 + 相关条目** |
| 0.30 ~ 0.50 | 最简提示 / 进候选 |
| < 0.30 | 不召回 |

同名候选分差 < 0.10 → 视为分不清（列候选或不召回）。

## 四、连带召回（只顺一层）

- 主人物档案里提到了别人 → 把那个"别人"也带一点出来；
- 带出内容 = **简版一行 + 他档案里提及主人物的条目**；
- 排序：关键度 → 被提及次数 → 更新轮次；
- **只用剩余预算，不挤占主人物**；预算不够时先砍关联条目，保住简版一行。

## 五、简版发什么

| 类别 | 内容 |
|---|---|
| **强制带**（不可关） | 姓名、**最后确认轮次** |
| **玩家勾选**（想勾几个勾几个） | 其余条目，每条取**最新一条值** |
| **不带** | 状态码 —— 能召回就说明他已离场，这个信息是冗余的 |

## 六、预算与装配

- 上限 **3000 字符**（可调 **500～6000**），是**天花板不是常态**；
- 常驻摘要（默认关）先扣约 8%；
- **两阶段**：① 人人先拿一行简版 → ② 剩余预算按分数把排前面的升级成全量；
- 勾选了的**唯一值条目**优先级最高；
- **一个人都没命中 → 返回空字符串**，这一段根本不加进请求。

## 七、注入与记账

- 注入位置：`turnSection`，默认放在酒馆自己的上下文**之后**；
- 每轮算一次，结果随这一轮保存，重试沿用（不重算）；
- 注入后记冷却：全量 → 人物级；简版／连带 → 条目级；
- 冷却**到期即删**，记录存整局数据。

## 十、写入这条链上的延迟

`判定延迟`（0~8 轮）→ `执行延迟`（0~1 轮）→ `生效`。但**时间标注不跟着漂**。

| 环节 | 延迟 |
|---|---|
| **明确离场**（正文写了离开/死亡） | 0 轮，当轮判定 |
| **模糊离场**（现场名单没他 + 连续 N 轮没出现） | 默认 **3 轮**（可调 1~5） |
| 模糊离场 + 勾了「待确认」 | 再 **+3 轮**（固定） |
| **手动提名**（只提名，不自动写入） | 默认 **3 轮**（可调 1~5），到期**直接抛弃不写入** |
| 最坏合计 | 自动+待确认 = **8 轮**；手动 = **8 轮** |
| **执行**：子代理写入 | 可能 **+1 轮** |
| **执行**：后台写入 | 0 轮（但玩家要等它跑完） |

**时间标注（gt）不漂**：

- 当轮写入 → 用快照头的 gt；
- 延后写入 → 值自带「捕获那一刻」的 gt，锚在**最后一次在场轮**（`anchors` 记的）。

> 例：最后在场第 10 轮 → 第 13 轮判定 → 第 16 轮写入，值挂的仍是 `turn=10` 与第 10 轮的 gt。

**归档缓冲**（见第一节）：归档时给该人物写一条冷却记录
`p:<人物编号> = { lastTurn: 最后在场轮, until: 最后在场轮 + N }`。
复用人**物**级冷却表，不新增结构；到期即删。
